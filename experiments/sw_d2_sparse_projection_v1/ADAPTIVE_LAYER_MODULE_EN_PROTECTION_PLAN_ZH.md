# SW D2 自适应层与模块选择＋英语保护元素更新：实验方案

状态：**待实施方案；本文不表示训练已启动或获得新结果。**
日期：2026-09-24。依托现有 experiments/sw_d2_sparse_projection_v1；新实验另设目录、协议 ID、配置与输出，不修改已冻结的五方法 release 或已有结果。

## 研究问题与依据

在相同 SW D2 数据和自定义 FP32 Adam 实现下，能否依据训练前的跨语言表征、目标训练信号及英语校准信号，选择需开放的层与 Attention/MLP 模块，并在模块内沿用现有英语保护逐元素更新，使 SW 能力提高且英语及通用能力少遗忘？

Tran 等人的 Findings ACL 2026 论文通过逐层跨语言句子检索和干预区分接口层与语义枢纽层，发现接口位置依语言和模型变化、Attention 在其 CPT 实验中有重要作用；其层标签来自**适配后**检查点，不应视作本实验 Base 上已知的标签。Zhao 等人的 NeurIPS 2024 论文提出输入理解、任务处理、输出生成的分阶段语言机制；这是工作假设，不证明 SW 的具体层号。当前 D2 混合有无标签语料、指令与双向翻译，不能直接套用纯 CPT 结论。

- https://aclanthology.org/2026.findings-acl.1218/
- https://papers.nips.cc/paper_files/paper/2024/hash/1bd359b32ab8b2a6bbafa1ed2856cf40-Abstract-Conference.html

本方案既**不固定选 10 层**，也**不强求 12.73% 单步写回率**。28 层均有入选机会，且同一层的 Attention、MLP 可以得到不同预算。参数写回比例、候选参数和训练成本须逐一实测、报告。

## 已有证据和待核实事项

现有 element_protected 对 element_unprotected 的 SW 阅读为 45.00% 对 43.33%，IFEval prompt strict 为 25.69% 对 21.07%，GSM8K strict 为 19.94% 对 13.42%；SW 阅读逐文章差值 +1.67 个百分点，95% CI [-1.22,+4.44]，不能代表跨训练种子的稳定收益。edge_projected_rows 对 edge_rows_no_projection 的 SW 阅读为 46.67% 对 44.22%；其差异同时包含方向和选行改变。本方案**保留方案一的英语保护分数，不加入方案二的投影**；投影机制另做后续消融。

既有历史 D2 FFT 已完成；本轮 fft_fp32_matched 是同优化器实现内对照。正式引用其 GSM8K 时先检查 DONE、产物哈希。旧新版 SW 阅读 44.89%/41.89%、EN→SW 36.34/19.38 chrF++ 的差距仍需审计更新与评测流程；不可擅自归因为 FP32 动量。

## 1. 冻结 Base 上的只读探测

探测只前向/反向，**禁止权重写回**；结束后从同一个 Base 重新初始化正式训练。全程写出所用样本 ID、随机种子、哈希及 28 层 × 2 模块组的原始和标准化统计。

### 1a. 跨语言接口 I

从训练侧取默认 512 对 EN–SW 平行句，和所有正式测试集按现有归一化/哈希规则去重；样本不足时报告真实数量。保持文本、token 过滤与句子池化方法一致，截掉指令模板和 padding 干扰。记录 embedding 输出与每一层 block 输出；每层对归一化句向量计算 EN→SW 与 SW→EN 句子检索 Recall@1，固定相同负例池，输出两条曲线、逐层值和重采样区间。低对齐层仅标记为接口**候选**，不可单独判定为训练必需层。

将逐层平均检索分数按论文启发做 2 类聚类，低分簇给 I_l=1，高分簇给 I_l=0；同时报告簇中心、成员及 bootstrap 稳定性。若聚类不稳或几乎所有层都同分，I_l 全部设为 0，并将接口指标作为诊断，不人为指定首尾层。论文是在适配后模型上使用检索分类，本流程用于 Base 选层属于需检验的新假设。

### 1b. 目标训练信号 T

以层×模块为单位，区分 Attention 的 q/k/v/o 与 MLP 的 gate/up/down；分别从四类 D2 训练来源抽取固定校准 minibatch，按正式配比合成诊断目标梯度，也保留各来源独立统计。于冻结 Base 上累计有限批次的模拟一/二阶 Adam 状态、构造**不写回**候选更新 Δ，记录单位参数目标动量强度以及一阶预计收益 max(0,-g_D2·Δ)/参数数。尽量与实际梯度裁剪和 Adam 顺序一致；模拟状态仅用于探测，正式训练重新初始化。用训练侧重采样报告不确定性，避免以单 batch 大梯度选层。此分数只是局部代理量，不能宣称等于下游收益。

### 1c. 英语风险 E

复用独立英语 instruction/reading/math 校准池，在同一 Base 上按现有方案一的梯度平方规则统计每个模块的英语敏感度，并记录对应梯度与 D2 候选更新的方向关系作诊断。英语梯度平方高并不等于更新必定伤害英语，因此在模块门控中只降低预算；最终训练仍使用现有逐元素保护规则。独立的英语验证样本留作诊断，不参与调档或选择。

## 2. 预注册模块选择规则

选择单位为 56 个层×模块组；最终 mask 文件须列出每个模块的 I、T、E、真实矩阵集合、可训练比例、入选理由、参数量及由此预测的单步更新量。不要用最终 benchmark 结果重新挑选模块。以下为 v1 的确定性默认规则；若因统计口径不适用要修订，须在正式训练前另存 v2 并说明原因。

- 在 Attention 组与 MLP 组**分别**计算 T 和 E 的第 25/50/75 百分位，避免两类模块的尺度直接比较。若一阶预计收益不为正，设所有该组矩阵的元素预算 q=0。
- T < 第 25 百分位：q=0。
- 第 25 百分位 ≤ T < 第 50 百分位：仅当 I=1 且 E 不高于第 75 百分位时 q=5%，否则 q=0。
- T ≥ 第 50 百分位且 E ≥ 第 75 百分位：q=5%，不完全排除共享参数。
- T ≥ 第 75 百分位且 E ≤ 第 50 百分位：q=25%。
- 其余 T ≥ 第 50 百分位的模块：q=15%。

同层 Attention 和 MLP 可以各自 q 不同。零基层号为 0–27；选择数量和全模型写回比例由规则自行产生。每个模块内的 q 对七个矩阵中的相应矩阵分别应用。计算每个矩阵 floor(q × numel)，记录实际离散化误差。若全部模块 q=0、缺失语言配对样本或跨来源 T 方向严重冲突，停止并输出诊断，不偷偷指定 10 层或查正式测试集来修复。保护版和机制对照必须使用**同一张**选择表。

## 3. 正式训练与唯一首轮机制对照

两个新模型均从 Base 独立训练，复用相同冻结 D2 样本顺序、优化器、学习率、seed、有效 batch 与 22,146 步。

- adaptive_protected：对开放矩阵维护候选 FP32 Adam 状态；沿用现有 element_protected 的矩阵内分数：归一化 |m_D2| / (1+归一化英语梯度平方敏感度)。每 20 步刷新元素 mask，每 200 步刷新独立英语校准敏感度。各矩阵 top 比例由选择表 q 决定。仅选中元素写回 BF16 权重，未选元素包括 weight decay 在内逐位不变。
- adaptive_unprotected：**相同**选择表、q、刷新周期、候选参数、数据与优化器；只去掉训练时每元素分数中的英语敏感度分母。这回答“模块选择固定时英语保护是否额外有益”。注意选择表本身仍使用 E，故该对照只隔离**元素级保护项**，不隔离门控中英语信号的作用。

两模型训练中开启验证并写 TensorBoard。记录各层/矩阵入选元素数、全模型每步实际写回比例、mask 变化、候选状态内存、峰值显存、GPU 小时，以及 BF16 实际非零权重变化。暂停/恢复后必须保持选择表及样本顺序一致。

## 4. 第三张 GPU：语言接口信号消融

若三张卡可在同一数据挂载下并行，先在单卡完成一次只读探测并冻结选择表，再启动三个相互独立的训练：

- GPU0：adaptive_protected（I/T/E 选模块；英语保护元素）。
- GPU1：adaptive_unprotected（**相同** I/T/E 选择表；去除元素级英语保护）。
- GPU2：adaptive_no_interface_protected（仅在门控时令 I_l=0，由相同 T/E、相同默认规则重新生成另一张选择表；其余采用保护元素规则）。

第三项检验语言接口信号是否帮助选层；因选择表和写回比例可能不同，须报告实际预算及表现取舍，不能把成绩差直接全部归于语言接口机制。三个任务分别使用独立输出目录和日志；GPU 编号只是建议，运行前先查 nvidia-smi、磁盘容量与是否已有任务占卡。不要将探测与正式运行并行，不能在服务器不可访问时声称训练已启动。

## 5. 验收、评测和结论边界

先进行短跑：检查层号、选择表哈希与恢复、正确逐矩阵计数、q=0 全冻结、未选中元素和其 weight decay 完全不改变参数；检测 BF16 量化导致的候选更新未生效。短跑通过后运行全量。最终核验 DONE、模型和评测哈希；分别报告 SW/EN Belebele、SW/EN XL-Sum、EN→SW、SW→EN、IFEval prompt/instruction strict、GSM8K strict/flexible。PPL/NLL 仅用于诊断。

比较顺序：先看 adaptive_protected vs adaptive_unprotected（元素级英语保护）；再看 adaptive_protected vs adaptive_no_interface_protected（接口信号的整体门控效应）；最后与原 element_protected、element_unprotected、edge_projected_rows、edge_rows_no_projection、新版密集 FFT 和 Base 同表展示。旧 FFT 仅作为历史参考。所有表同时列出候选比例、单步写回比例、GPU 小时、峰值显存；不要求固定 12.73%，但不能在不同预算时宣称纯粹的选层因果收益。SW 阅读可做逐文章配对区间，**单 seed 不证明跨训练稳定性**；出现正向结果后再补不同训练 seed 和 IG D2 迁移。IG 摘要存在训练文本重叠时须单列限制。
