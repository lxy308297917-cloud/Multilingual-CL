# SW D2 两种新方法与同数据对照简介

## 共同问题与数据

目标是在单语言 SW 微调时保留阅读、摘要和双向翻译收益，同时减少英语和通用任务遗忘。五个新模型均独立从 Qwen2.5-1.5B-Instruct Base 初始化，使用同一冻结的 SW D2 样本顺序、seed42、15,360,372 个非 padding 输入 token、22,146 个优化步及长度 2048。输入 token 配比是 FineWeb2 70%、Aya 10%、EN→SW 10%、SW→EN 10%。因此两种新方法之间主要变化是参数更新规则；并未改变训练语料。已有 SW D2 FFT 在优化器精度等细节上不同，仅为历史参考。

## 方案一：英语保护的动态逐元素稀疏更新

候选是全部 28 层 Attention/MLP 的 196 个二维线性权重矩阵；embedding、LM head、Norm 和 bias 冻结。每个矩阵按目标训练梯度的一阶动量强度选出 15% 元素，每 20 步刷新掩码。保护版额外用独立英语校准池计算梯度平方敏感度，训练前和每 200 步按固定规则抽取 32 条英语样本更新；在矩阵内归一化目标强度及英语敏感度，以目标收益与英语变化风险的比值排序，保护系数为 1。未被选中的元素仍维护候选动量，但本步的梯度、动量和 weight decay 都不能实际改动它们。

机制对照 `element_unprotected` 取消英语敏感度项，保留相同的 15% 元素预算、刷新周期、数据及训练设置。两者比较检验英语保护项的贡献。模型选参会随训练变化，所以“动态”指掩码刷新，不是训练中改变配比或学习率。

## 方案二：首尾层结构化投影更新

只处理零基编号 1–5 与 23–27 层的 Attention/MLP 线性矩阵。训练前用独立的 256 条英语样本，为每个候选矩阵冻结秩 32 的输入子空间 U。先计算完整候选 AdamW 更新 Δ，再施加 Δ′ = Δ − 0.5(ΔU)Uᵀ，以削弱在英语校准子空间中的更新分量。随后按投影后每行的均方根更新幅度，在每个矩阵选择 50% 完整输出行；行掩码每 20 步刷新。

机制对照 `edge_rows_no_projection` 保留相同层、完整行预算与掩码刷新，但投影强度设为 0。两者比较检验投影本身是否有价值。50% 是候选矩阵中的行比例，并非全模型参数更新比例；实际比例另行记录。

## 为什么共五个新模型

两个新方法各有一个只去除关键机制的对照，另有 `fft_fp32_matched`：同数据、同预算、同 FP32 Adam 动量设置的密集全量微调参照。故为保护版、去保护版、投影版、无投影版和密集 FFT，共五个新模型。历史 D2 FFT 结果继续展示，但不代替同协议密集 FFT。

全部模型只使用预算终点权重，按相同固定任务评测 SW/EN Belebele、SW/EN XL-Sum、双向 FLORES 翻译、IFEval 和正式 5-shot GSM8K；PPL/NLL 仅为诊断。主要判断 SW Belebele 的逐文章配对差值及 95% CI，同时检查英语和通用任务。已通过 DONE、任务身份和产物哈希核验的原始成绩见 REPORT_ZH.md；未完成模型不得提前下结论。MMLU/G-MMLU 延期。
