# SW D2 方案一：供外部审查的实验说明与结果

本材料只汇报已完成且通过 DONE、任务身份、模型身份及产物哈希核验的方案一两版。方案二投影/无投影及同优化器精度密集 FFT 尚未有完整下游结果。

## 研究问题与对照关系

在固定 Qwen2.5-1.5B-Instruct Base、SW D2 输入、顺序、预算和评测协议后，英语保护动态稀疏能否在 SW 阅读与翻译收益之外更好保持英语及通用能力？`element_protected − element_unprotected` 才直接检验英语保护项；`element_protected − Base` 是净收益/遗忘；`element_protected − D2_历史FFT` 是参考比较，但历史 FFT 使用标准 `adamw_torch`，本轮稀疏实现使用自定义 FP32 动量，不能仅凭此差值归因于稀疏/保护。冻结队列中的 `fft_fp32_matched` 结束后，才形成更严格的密集对照。

## 数据与训练身份

- Base：`/root/models/Qwen2.5-1.5B-Instruct`；两版独立从 Base 初始化，seed42，SW 单语言独立训练。
- D2 配方按完整非 padding 输入 token：FineWeb2 CPT 70%，Aya SFT 10%，EN→SW 10%，SW→EN 10%。同一冻结 manifest、训练池、开发池、样本顺序与 tokenizer/chat template。CPT 监督文本续写；SFT 只监督 assistant 答案及结束符。
- 精确实际输入 15,360,372 token；监督 12,175,915 token；44,292 次样本呈现；22,146 optimizer steps；统一长度 2048；最大重复 2 次；不截断完整 SFT 样本。
- 按来源：CPT 输入 10,752,000/监督 10,746,750，Aya 1,536,167/642,969，EN→SW 1,536,081/497,648，SW→EN 1,536,124/288,548。
- 有效 batch 2（microbatch1、梯度累积2）；每样本先对非忽略监督 token 的预测损失取均值，再对样本取均值。BF16模型和梯度检查点；AdamW一阶/二阶系数 0.9/0.999、epsilon 1e-8、weight decay 0.01；lr5e-5、cosine、warmup5%、clip1.0。新方法的候选矩阵动量状态用 FP32。初始、约20/40/60/80%和预算末尾测固定开发集，只取最终权重。

## 方案一精确定义

- 候选是28层全部Attention/MLP的196个二维线性权重，共1,310,195,712个候选参数；embedding、LM head、Norm、bias不更新。每矩阵选约15%个逐元素更新，实测当前掩码共196,529,312个选中元素。
- 目标梯度的Adam一阶动量 m 与二阶动量 v 对全部候选维护。每20步根据当前 m 刷新矩阵内的选择掩码。先令 t=|m|/(mean(|m|)+1e-12)。未入选元素的模型权重本步精确不变，包含weight decay；但候选动量仍积累。
- 英语校准池是独立冻结的 instruction/reading/math 三类各256条 scoring 样本。保护版训练前及每200步按固定轮转抽32条（11/11/10）求英语梯度；每矩阵维护其梯度平方的指数滑动量 s（0.9旧量+0.1新平方）。令 r=s/(mean(s)+1e-12)，保护版按 t/(1+r) 排序，每矩阵取前15%。不保护对照直接按 t 排序，其余条件相同。
- 校准池与 D2 train/dev 的20-token正文精确窗口扫描未发现重叠；此检查不覆盖短片段、近重复或语义重叠，不能称为绝对无污染。
- 保护版训练记录约7.27 GPU小时，去保护版约5.71 GPU小时；两者都经历服务器中断和检查点恢复，重跑量不同，这个差值不能全部归因于英语校准。保护版实际校准轨迹有129次计算、111个唯一计划步点，因恢复重放18个步点；校准累计处理934,179输入 token、236,284监督 token，记录的校准计算墙钟合计约1.30小时。这些额外token不计入15,360,372目标训练输入预算，但计入实际计算成本。

## 评测协议

每模型 seed42 单次：SW/EN Belebele各900题准确率；SW/EN XL-Sum固定500条chrF++；FLORES双向翻译各固定500条chrF++；IFEval prompt/instruction strict；lm-evaluation-harness 0.4.8 正式5-shot GSM8K strict/flexible。沿用固定样本、few-shot、prompt、chat template、解码和评分。MMLU/G-MMLU延期。PPL/NLL单列诊断，不进入能力综合。

## 当前解释和待审查点

1. 保护版相对去保护版在SW阅读高1.67 pp，但CI跨0；不能宣称阅读提升已获统计证据。保护版与历史FFT在SW阅读仅差0.11 pp，CI也跨0。
2. EN Belebele、IFEval和GSM8K的原始分数，保护版均高于去保护版及历史FFT；但IFEval和GSM8K仍明显低于Base。不能宣称已解决通用遗忘。EN摘要保护版略低于去保护及历史FFT。
3. 保护版SW→EN比历史FFT高3.93 chrF++，EN→SW高0.58；翻译改进为描述性单次结果，尚无对应逐句区间和跨seed证据。
4. 历史FFT的`adamw_torch`与新方法自定义FP32动量存在实现/精度差异，不能把保护−历史FFT直接解释为纯方法效应。同设置密集FFT仍在队列中；方案二及其消融亦未完成。
5. 本轮只有seed42，所有区间只反映固定模型在固定测试集的配对抽样不确定性，不代表训练随机性的稳定性。校准与训练的精确窗口排重、测试重叠扫描都不等于语义去重。SW固定摘要测试对CPT输入的13词精确窗口扫描未发现匹配，但双向翻译输入至少有1条匹配；这不足以证明无近重复或语义污染。

供审查时建议重点质疑：英语校准样本是否代表要保留的能力；t/(1+r)的尺度及0.9敏感度动量是否合理；15%预算和20/200步刷新是否与计算成本公平；候选动量对未更新元素持续累积会否产生滞后效应；相同输入预算下更新参数量与额外校准计算如何纳入公平比较；单seed与多个下游指标如何控制偶然性。
