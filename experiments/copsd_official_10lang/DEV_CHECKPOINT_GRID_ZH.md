# 独立开发集 checkpoint 曲线

2026-10-20，六种语言100更新训练结束后补充。SW、TH、BN、DE、FR的最终开发分数下降，ZH单训练seed上升；因此统一补齐六语言的0／20／50／100更新曲线，检查早期收益和后期退步。此网格是在看到开发端点后设定的探索分析，不是预注册确认性实验。正式测试分数不作为checkpoint、语言或题目选择依据。

- 使用保存的训练checkpoint，不重新训练，也不缩短原100步学习率日程。
- SW、TH复用同一vLLM协议已完成的20更新结果；所有语言复用Base及100更新结果。共需10个新评测进程，每个100道独立开发题。
- 协议保持project_dev_single_vllm_v1、n=1、2048上限、temperature1、top_p0.95、top_k−1、相同逐题seed规则、官方提示及评分器；不混用历史HF结果。
- 汇总从原始逐题结果核对题目、答案、prompt、保存的seed及除adapter／输出外的配置，重新统计正确题数；缓存结果不重复计入新增生成成本。
- 同一开发集选最佳checkpoint会有选择偏差；曲线不能证明稳定收益。三语言选择仍须结合必要的独立训练seed复测、语言保持、稳定性与成本，不强行从退步结果中选三种。
- 原始模型、adapter、旧结果、运行中的训练和评测代码不修改。新任务为单卡，账号总计上限4，等待卡位，手动启动一次，不自动重跑失败项。

入口：`run_dev_checkpoint_curves.sh`。CPU `--check-only`已逐语言通过，确认20／50更新状态与权重存在、输出目录全新、SW／TH缓存20更新确属对应adapter。完整GPU曲线及配对汇总尚待执行，不把预检称为效果结果。
