# 普通SFT方向风险选参：核心实现

状态截至2026-10-27：核心实现、CPU检查和真实Qwen技术预检完成；五组科学实验尚未全部完成，没有新方法效果结论。这里公开的是可审阅核心，不是完整训练及评测入口。数据、逐题回答、checkpoint和服务器运行日志不上传。

## 本目录

- `optimizer.py`：精确稀疏名额、AdamW候选、BF16反事实风险、状态保存与恢复。
- `calibration.py`：顺序英语CE校准与0.1回放；恢复RNG和各模块训练模式。

依赖PyTorch、NumPy。训练侧调用方需提供可训练参数字典、逐矩阵整数名额、主训练梯度及校准损失函数；必须在写回前完成约定的裁剪和学习率调度。此核心类没有实现通用PyTorch Optimizer接口，不可直接替换任意Trainer的optimizer参数。

## 五组与共同设置

U：无保护；P：平方英语梯度敏感度；R：相同池的0.1 CE回放；N：仅惩罚正方向风险；N_abs：绝对方向风险。

196个Attention/MLP二维矩阵，逐矩阵floor(15%×元素数)，总K=196529312。mask每20步刷新；P/R/N/N_abs共用每20步8例的校准日程。BF16权重，FP32 Adam动量；未入选坐标的动量也推进一次，参数只在mask内写回。embedding、head、Norm和bias冻结。完整数据与评测范围见[进度入口](../../BENCHMARK_DIRECTION_PROGRESS_20261026_ZH.md)。

## 核心定义

1. 从本组训练梯度计算一次完整AdamW候选位移d，包括动量、预条件和weight decay。R的训练梯度含显式回放CE；P/N/N_abs的校准梯度不进入Adam动量。
2. q=FP32(BF16(theta+d))-FP32(theta)，表示未做稀疏限制时的反事实BF16位移。
3. a为逐矩阵归一化的Adam第一动量绝对值；e为英语参考CE梯度的有符号EMA，beta=0.9，第一次观测直接初始化。r=e*q。
4. N的评分为a/(1+max(r,0)/(mean(abs(r))+float32.tiny))；N_abs将正部改为绝对值。P沿用平方梯度敏感度评分。
5. 稳定排序并处理并列名额，更新精确入选位置。这里改变选择，不做更新投影或方向修正；weight decay也不能写到mask外。

风险权重固定1，不依据开发成绩选系数。零学习率时风险为0，N/N_abs退回无保护评分，首20步使用对应mask。英语校准梯度在两次刷新间会陈旧。这是局部启发式，没有不遗忘保证。

## 校准语义

非回放组在主梯度产生前顺序计算英语参考CE梯度，将估计转至CPU并清空参数grad；恢复Python/NumPy/Torch/CUDA RNG及每个模块的训练模式。R保留0.1倍辅助梯度，再添加主梯度并统一裁剪一次。调用顺序是算法的一部分。

校准池不是已认证的Base掌握题池。本轮没有新增EN/SW配对机制，也不主张梯度乘位移或符号门控本身具有充分创新性。

## 验证范围

本机CPU检查覆盖U/P历史公式一致性、精确名额与mask外不写回、符号改变选择、尺度检查、恢复继续训练及校准隔离。真实Qwen预检覆盖最长主样本、完整checkpoint恢复后位移与状态逐位一致。

上述技术检查不等于下游效果验证。五组统一筛查、与N_abs的符号消融及与回放的比较未完成前，不宣称新方法胜出；后续也必须遵守预定的第二顺序和SSU/HFT门槛。
