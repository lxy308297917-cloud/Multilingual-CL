## 当前方案与解释边界

原英文阅读自译方案已因质量问题停用，当前 v4 改用官方原生 Swahili TyDiQA-GoldP。A为纯FineWeb2 CPT，B为纯Aya SFT，C为多任务SFT；三组独立从Qwen2.5-1.5B-Instruct开始，FFT、seed42、每组15.36M非padding输入token、统一最大长度2048。

C名义配比为Aya55%、阅读10%、双向翻译各10%、摘要15%；阅读最多三次的容量不足部分在冻结前转给Aya。完整样本采样后的实际占比约为Aya55.65%、阅读9.34%、双向翻译各10%、摘要15.01%。阅读完整上下文很长而答案短，输入占比不等于监督量占比。

主要观察SW Belebele及英语、通用能力保持；PPL/NLL仅作诊断。D是历史混合FFT参考，不是严格受控对照。C摘要收益属于同分布监督泛化。C−B同时改变多个任务配方，不能把全部差异归因于TyDiQA；Aya本身也含CoQA。
