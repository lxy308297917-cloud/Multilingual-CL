# EN–SW 表示对齐：2026-10-21 首轮

研究问题：固定内容的跨语言表示对齐，能否在相同 SW SFT 之外改善实际 SW 任务，同时保留英语？先检验效果，不预设原创性。

本分支与运行中的稀疏 A/D/R 分离。这里 align-A/B/C/D 全部更新 Qwen2.5-1.5B-Instruct 原参数；没有 LoRA、逐元素 mask 或 OPD。旧完整 Dense 只用于表示诊断，缺少匹配前缀 checkpoint，不能代替新 align-A。

| 组 | 主流以外的辅助项 | 用途 |
|---|---|---|
| align-A | 无 | 原始 Dense SFT |
| align-B | 同池双向翻译 CE | 排除额外监督的解释 |
| align-C | 固定 Base EN 与当前 SW 的 1−cos | 拉近正确译文 |
| align-D | SW→固定英语全池 InfoNCE | 拉近正确译文并区分非译文 |

共同主流为原冻结 Aya80/双向 MT20 非 padding 输入 token 配方。10% 完整预算的首个完整 batch 边界是 4293 更新、1536351 输入/599469 监督 token。有效 batch2；完整42465步 cosine，warmup2124、lr5e-5、AdamW wd.01、BF16 权重与动量，与核验后的旧 Dense 一致。embedding/head/Norm 也训练。损失为每例参考 CE 均值。

每4步辅助8个固定顺序的同题对；系数一次固定为.1，不看下游分数重调。B 两方向16例 CE，C/D八个SW内容前向，D使用2000个冻结英语向量为负例库，温度.07。对齐内容不含翻译提示或答案前缀，最长SW256/EN192，不静默截断。主流/辅助/teacher token、前后向及耗时不同分别记账，不能声称严格等算力。固定系数的损失尺度不同是解释限制。

## 依赖顺序

```mermaid
flowchart LR
  S[原始平行源与共同ID] --> Q[逆向一致性/数字/语言/近重复核验]
  Q --> V[Base开发集逐层检索]
  V --> L[按预定规则冻结单层]
  L --> T[缓存冻结Base英语表示]
  T --> M[真实长样本/恢复与显存预检]
  M --> A[四组同前缀训练]
  A --> E[同一独立下游开发评测]
  E --> R[与CE对照比较并决定止损]
```

Base开发集500对按平均池化双向 cosine P@1 选一层；同分优先靠近14然后较小层号。选层不用1000对独立诊断或下游分数。hidden_states[0]是embedding，1..27对应层输出，28是final norm之后；训练和诊断保持一致。另报告最后内容token、位置加权池化、严格 MEXA 行列均胜出、正/负配对差、异句总体相似度和方差。人工困难句仅为助手审阅的数字/否定/关系诊断，未冒称母语人工金标。

训练池2000对来自完整主训练流将使用的MT原题群组，短前缀中多数尚未曝光，因此相对A是额外材料。B用于控制同池额外监督。开发/诊断按共同ID划分，排除全部主MT和固定下游/正式测试文本；数字归一化字符3–5gram TFIDF .80阈值排近重复。此筛选不等于语义去污染证明；原Aya与NLLB整体噪声仍是限制。公开测试只用于排除内容，不用于训练、选层或选参。

## 预算与验收

新线独立总上限24 GPU小时（含失败）；训练每组最多3h，开发每模型1.5h，诊断2h、技术预检1h。只运行一个seed、一个预定层、一个辅助权重和一个4293终点，途中checkpoint只恢复。全参数最长样本和32步吞吐不过则停止并保留错误，不能暗改精度或科学预算。账号临时最多5卡只配置新sw-align队列，旧四卡默认不变。

预计明晚前提供逐层曲线与四组短预算开发结果，以真实资源与预检为准。SW阅读/双向翻译为主要收益，EN阅读/指令/数学为保持；表示只作诊断。所有同协议逐题输出、语言/截断、token、TensorBoard和可恢复状态保留。若对齐仅改善检索、未超过同池CE，停止扩展。英语准确率相对A额外降低超过2个百分点不升级。单seed开发差异不是长训/原创性结论，升级还需置信区间、正确/打乱配对和新增seed确认。本轮不自动启动这些扩展。

## 文献定位

[MEXA](https://aclanthology.org/2025.findings-acl.1385/)区分双向严格检索与余弦平均，因果模型还比较加权/最后token。跨语言相关性不能证明当前SW适配的因果收益。

[Middle-Layer Representation Alignment](https://aclanthology.org/2025.acl-long.778/)已有中层对比对齐、任务与对齐交替步骤；文中英语stop-gradient并无一致收益。本轮全池固定Base英语缓存、联合目标、1.5B单SW数据是明确变体，不能称为原论文复现或既定有效方案。若有效再复现交替强基线，暂不增加变体。

## 数据质量门（启动前修正）

初始自动QA的60对抽查含明显语义错配，故初始候选池不能用于训练。追加本地Qwen3-8B双顺序语义筛选，不下载新模型。先用助手审阅的10个明显错配与36个基本忠实的哨兵检验：固定YES/NO相对概率阈值.9、两种顺序均通过；预定门槛拒错配≥8、留忠实≥25，实际9/10与31/36。漏掉的已知实体错配也按人工审阅清单排除。该概率没有校准为语义正确率，不能称为母语金标。

只扩展一次候选上限：主流同题3500对、完全未用于主流的训练侧保留2500对。按固定顺序取首2000个合格训练对及1500个保留对，后者前500选层、后1000独立诊断；不足即停止，不看下游补数据。保留池增加未进主流的原训练源，不是只依赖原dev。所有原题仍按共同ID和近重复隔离。语义筛选最多2 GPU小时，含在24 GPU小时总账内；候选质量后验样本还须复核，未通过不启动对齐训练。筛选会引入语言风格/领域选择偏差，B/C/D复用完全相同池控制这一因素。原主训练数据流保持不变，其固有噪声另记。

预先冻结的探索性任务门：C、D分别比较B，EN→SW chrF++配对95%区间下界>0；SW阅读F1下界不低于−2点，SW→EN chrF++不低于−1；与A相比，英语阅读、数学、指令各自主要正确率差异的下界都不低于−2点。两种变体和全部任务均报告，不把未经多重检验确认的单次开发结果当作定论。即使通过，也不自动释放长训。

最终启动前又统一排除了跨语言规范化字符复制比≥.65的句对和已知语义歧义，所有补充仍在3500/2500候选上限内，复用已有语义判断，仅新增45535质检输入token。另对全部主流Aya的104764条prompt/answer字段执行同阈值近重复审计，保留候选没有≥.80重叠。最终池为2000/500/1000，60例最终助手复查完成。数据仍含直译和不自然语法，不能声称母语金标，也不能由负结果宣称对齐思路普遍无效。原始候选、被拒绝池、各次筛选逐对记录和代码版本均保留，未改原始数据。

## 恢复预检修复 v2（尚未启动正式4293步训练）

v1真实4→8续训与连续8步的权重不同；不同方法在第一个辅助事件前的主CE也不同，默认CUDA非确定性是首要嫌疑。全部v1代码、日志、失败权重与成本保留。独立v2分支启用torch确定性算法、cuDNN确定性和CUBLAS_WORKSPACE_CONFIG=:4096:8，要求各方法前4步主CE/前3步梯度范数完全一致，再检查恢复后的全权重、Adam动量和scheduler。若仍失败则继续诊断，不能声称已解决。

新技术输出在technical_deterministic_v2；完整科学训练数据、损失、系数、温度、层10、优化器精度、学习率日程及端点均不变。已有完整Dense仍仅诊断参考。B/C/D技术短跑只保存实际权重/动量相对A的差异计数与日志，不再保存无恢复用途的额外大检查点；A保存三份用于真实恢复对照。正式每组中点/终点恢复状态仍完整保存。技术失败已计入同一24 GPU小时总账，无额外扩容。

## 成本记录序列化修复 v3

v2确定性恢复完全通过；完整模型、Adam两动量、scheduler及独立审计的Python/NumPy/CPU/CUDA RNG与计数均一致。A组在32步写成本门时遇到numpy.bool_不能JSON编码而退出，参数更新本身有限。v3将成本门生成集中为原生float/bool并增加实际函数回归检查；仅改变记录代码及独立输出comparison_v3，不改训练数值。A32未存checkpoint，故从Base重跑，不伪造续训。旧A失败输出和日志原地保留，已通过的技术验证不重跑；B/C/D旧等待队列已安全停止，在新v3命名队列恢复。

曝光审计更正：辅助2000对中1759对不在4293步主前缀，236对仅出现一个翻译方向，5对两个方向均出现；C/D只与A比较会混入额外曝光收益，必须与同池CE的B比较。数据不变。最终结果仍遵守原24 GPU小时总预算和单终点协议。

辅助计算吞吐修正（正式A/B/C/D出分前）：实测A前32步平均0.938秒，串行B辅助事件比无辅助压力步多6.804秒，推算B需3.147 GPU小时，超过原3小时上限。因此不启动已知超预算的串行B，将辅助microbatch统一为4：B为16例的4批，C/D为8例的2批，频率/8对/全2000英语负例库/每例损失权重均保持不变。主microbatch1×2不变。FP32目标梯度的分批等价检查通过；BF16累加次序会改变，故在独立输出重新做真实B/C/D压力、实际写回与成本门，不能声称与归档串行压力步逐位等价。此工程优化不增加科学变体或下游选参次数。

## 运行中只读优化器审计（不更改设置）

新四组从启动即统一为单参数组AdamW wd=.01，旧HF Trainer分197个衰减张量与141个不衰减的bias/Norm张量。此前“沿用旧设置”仅对参数范围、beta/eps、BF16权重/动量等成立，不能据此声称配置逐项相同。进一步对65280种有限BF16位模式及实际141个一维张量（144896元素）检验，在本轮最大LR5e-5、wd.01的独立乘法中所有位保持不变；安装的torch eager foreach源码先单独BF16乘衰减，再做自适应add。由此推断此实现下名义分组差异不产生衰减位移，但未做另一参数分组的CUDA整步重放。报告中保留该限定，不推广到FP32/master权重或fused优化器；旧完整Dense依旧只作描述性参考，不替代新A。四组内部设置匹配且运行中没有改变。完整证据见报告OPTIMIZER_GROUP_AUDIT.json与DENSE_BF16_DECAY_AUDIT.json。
