# OP-RASP 分阶段实验草案

日期2026-10-09。**未启动GPU训练；这些是建议协议，数据、超参和release尚未冻结。**

## 阶段0：否决不成立的前提

1. 在全新训练侧翻译/指令切片检查示范教师相对无示范版本是否真实提高输出正确性；学生prompt不带示范。若1.5B只复述参考或不能利用上下文，停止纯SDFT路线，另评估合法更强教师，其成本单列。
2. 用两批互不重叠的当前学生rollout估计选参score及预测整体更新效应，报告重复性、mask Jaccard及任务分项，不将Jaccard高本身作为收益。
3. 在独立训练诊断batch临时应用组合稀疏delta，比较预测/实际新旧局部损失变化并严格恢复权重。没有稳定方向，不升级代理选参；这不是下游收益证明。
4. 最多单卡技术短跑20—50步验证Qwen适配、内存、tokens/s、参考模型驻留与缓存开销、梯度裁剪/调度及未选位置冻结。不得仅凭CPU toy通过就长训。

## 阶段1：最小正交机制比较

|状态采样|参数选择|目的|
|---|---|---|
|固定示范前缀|原动态英语保护|off-policy参考|
|固定示范前缀|候选风险排序|分离选位主效应|
|当前学生前缀|原动态英语保护|**核心 sparse-on-policy 强对照**|
|当前学生前缀|候选风险排序|候选完整方法|

四组在相同教师/参考目标、逐矩阵名额、优化器、mask刷新周期、任务prompt身份和数据曝光预算下比较，差别只为指定因素。原保护排名20步与候选每步不同会混淆，因此四格首轮统一每步，并另保留旧20步组作历史机制参照。off-policy四格对照也是蒸馏，不是直接把CE-SFT当成相同目标。

另加普通稀疏CE-SFT、密集on-policy蒸馏和英语CE回放作外部基线。真实SDFT/iSDFT的教师策略、目标和超参数按原实现独立核查；原型不充当论文基线复现。

短程建议2048优化步，学习率使用正式日程前缀而非2048步cosine归零。监督子轨道与D2不同，prompt数、真实生成token、demonstration-token、教师打分token和有效损失token均记录；不能宣称这些与旧D2 token数完全相同。

预算面：同更新名额与目标prompt曝光是一套比较；教师/rollout计算较高时还须比较同GPU小时的学习/保持前沿。报告采样温度、EOS、平均/尾部长度、mask历史并集、实际BF16写回与最终差异，禁止将15%写回名额解释为85%算力节约。

只在独立开发筛选和确认切片上选择一次方案。建议准入：新任务至少一主指标可信改善，旧阅读/指令在预注册非劣界内且不靠某一项掩盖下降。数学评分先解决格式偏差；没有同任务SW阅读开发集时明确缺口。具体门槛、样本量和比较次数需在真实生成前冻结，不继续消耗旧正式测试调score。

## 阶段2：真正的continual learning

单次Base→SW适配是“学习新能力且保留”，不足以充分证明多阶段CL。先建立至少3阶段可审计训练流，例如SW翻译→SW摘要/指令→IG翻译，并预先固定反向顺序检验顺序效应。样本来源与任务边界尚未批准为正式benchmark；必须核查跨阶段去重与来源许可。

每阶段所有组继续上阶段学生（不重置Base）；上一阶段参考随阶段冻结，原始Base一直固定；对所有已学任务使用合法记忆prompt，固定总记忆token上限。各方法看到相同记忆预算，不得只给候选旧任务数据。

每阶段完成后建立成绩矩阵A[t,j]（阶段t后在任务j的固定分数）；单任务分别计算BWT_j=A[T,j]-A[j,j]、forgetting_j=max_{t=j..T}A[t,j]-A[T,j]。accuracy、chrF等不同单位分别报告，跨任务均值需先明确归一化，不能裸平均。FWT需要学习前对应任务测评及共同Base参照。英语IFEval/GSM8K独立保留。

核心出现可重复收益后至少补2—3训练顺序/种子、预算5%/15%及独立模型规模；这些是论文证据需求，不是本轮立即开卡清单。

## 阶段3：必要消融和停止

- 同on-policy loss下原排名 vs 风险排名：新选参是否真的起作用。
- 去一阶旧风险、去二阶敏感度代理、magnitude等名额：是哪项提供收益。
- 固定Base参考 vs Base＋上一阶段参考：是否保留新学技能。
- 等长度/等采样预算的陈旧轨迹窗口：若每步重采样太贵，明确near-policy成本取舍。
- 预测风险与真实变化的误差；若代理失效、教师无效、强对照无收益或成本明显恶化，停下并报告负结果。
