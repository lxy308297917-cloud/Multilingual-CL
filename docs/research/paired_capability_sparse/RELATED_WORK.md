# Closest prior work and novelty boundaries

Checked 2026-10-21 using primary papers/official repositories. These are scoped comparisons, not reproductions or an exhaustive novelty search.

| Work / primary source | What is already established | Boundary of this prototype |
|---|---|---|
| [GEM](https://arxiv.org/html/1706.08840v5), method section | Episodic-memory task losses give inequality constraints; a quadratic projection changes interfering gradients minimally. | Memory-based halfspace protection is prior art. We restrict a displacement to an element mask and include AdamW state; this alone is not a new research contribution. |
| [Source-Shielded Updates (SSU)](https://aclanthology.org/2026.acl-long.865/), abstract and official source at [gucci-j/ssu](https://github.com/gucci-j/ssu) | Source-calibration importance identifies columns to freeze before target-language adaptation. | Original English-sensitive ranking/freezing is a necessary comparator. The new data are supervised Aya/translation, unlike SSU's unlabeled adaptation setting, and must be labelled as a port. |
| [UP-MOPD](https://arxiv.org/html/2610.08398v1), §§2.1–2.3, Appendix C.4 | Form full optimizer displacement, retain the optimizer state advanced from the original mixed gradient, project only infeasible candidates to the closest joint halfspace solution. Check realized finite-precision displacements. | **Direct overlap with the proposed optimizer intervention.** Sparse support and correctness-conditioned bilingual calibration alter the problem inputs, not the existence of this update-projection idea. No claim of original AdamW displacement projection. |
| [Subspace Tuning](https://arxiv.org/html/2610.22293v1), optimizer enforcement discussion | Protect principal singular directions by constraining the optimizer's applied update rather than only its raw gradient; refresh the spectral anchor. | No SVD or spectral anchoring in this prototype. Dynamic coordinate support and capability-gradient halfspaces are different constraints, without importing SST's guarantees. |
| [Composable Sparse Fine-Tuning](https://aclanthology.org/2022.acl-long.125/) | Learn sparse language/task adaptations and compose them for cross-lingual transfer. | Sparse adaptation and cross-lingual modularity predate this project. Here one model updates during adaptation; no post-training expert composition. |
| [Multilingual Fine-Tuning via Localized Gradient Conflict Resolution](https://arxiv.org/html/2606.05613v1), §3.2 | Bucket-level language-gradient multi-objective optimization (MGDA, CAGrad, PCGrad) resolves localized multilingual conflicts efficiently in distributed training. | Cross-language gradient conflict resolution is established. This prototype solves one global QP on a fixed element support and applies it to the AdamW candidate; blockwise storage is not blockwise MOO. |
| Existing repository OP-RASP, `experiments/on_policy_sparse_cl_v1/core.py` and `docs/research/on_policy_sparse_cl/METHOD_ZH.md` | CPU prototype for fresh student trajectories, teacher/reference local KL, and risk-aware ranking of actual AdamW candidates under exact per-matrix budgets. | Reuse conceptual candidate-update accounting, all-coordinate FP32 moments, exact quotas, state/RNG isolation discipline. Change objective to ordinary CE-SFT, keep old mask ranking to isolate correction, replace risk-ranking with a support-constrained joint QP; add explicit joint-mastery weights and pairing shuffle. No OPD rollouts, demo teacher, empirical Fisher term, or claim of strict on-policy training. |

The only narrow contribution hypothesis remaining is whether **correctness-conditioned joint bilingual information**, beyond separate language protection and matched exposure, improves actual learning/retention at acceptable cost. The first F is deliberately simple joint-mastery weighting. Pair shuffling and E can falsify it. Pairing must change actual gradients/updates on the real pool, not merely metadata. An improvement over A alone cannot establish the contribution.

A nearby data-selection precedent also matters: [Cross-Lingual Pitfalls](https://aclanthology.org/2025.acl-long.404/) already studies English-correct / target-language-wrong pairs. The present audit read its official abstract/repository summary via the prior local evidence and rechecked the primary page; it is not a new discovery claim. The narrower training-time retention intervention still needs evidence.
