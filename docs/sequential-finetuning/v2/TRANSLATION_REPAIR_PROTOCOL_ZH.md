# 用同源译文修复指定输出语言的小实验

从 MASSIVE 5e−5 全参原序终点开始，检验平行配对是否给普通的双语 SFT 带来额外收益。结果属于机制预试验，使用一个模型检查点和固定种子 42。

从 MASSIVE 1.1 作者训练集选 256 个具有英文、SW 和 UR 版本的共享源 ID。候选排除全部 V2 MASSIVE 顺序条件中已经使用的训练 ID，并核对三语的意图与槽位多重集一致。英语原句统一作源文，SW 和 UR 两个本地化 utterance 作对应参考。训练指令及 `Translation:` 续写格式沿用 FLORES 零例英文标题。 [实际生成提示](FLORES_PROBE_PROTOCOL_ZH.md)

三个 LoRA 适配器都从同一个全参终点开始。rank 16、alpha 32，Attention 与 MLP 投影一致。每 8 个源题更新一次，共 32 次，学习率恒为 5e−5。每个源题构造两种目标语指令与两种参考答案的四格组合。正确目标语的两格做词元平均 SFT，包含结束标记。交互项对回答使用词元平均对数似然，排除结束标记，计算匹配两格减交叉两格的和。

| 条件 | 配对关系 | 训练损失 |
| --- | --- | --- |
| 双语 SFT | 两个正确目标与原句配对 | `SFT`，计算同样的四次评分，交互权重为零 |
| 真配对 | 错误目标语是同源的另一语言译文 | `SFT + 0.2 × softplus(1 − 交互量)` |
| 批内打乱 | 错误目标语仍在同一批内，但来自下一个源题，正确输出维持原配对 | 同一交互损失与权重 |

三个条件的正例、源题次序、更新数、输入与候选词元预算相同。打乱组用于检验相同语言曝光和训练目标下，同义反事实的贡献。保留两项共同评测。FLORES 开发集使用原来相同 80 个互异文章源题，主指标为 SW 和 UR 两语等权的语料级 chrF++，同时记录逐语目标语言率。MASSIVE 对同源 128 道开发题在五语上用原提示和作者槽位评分，检查原任务保留。所有结果为开发诊断，未使用正式测试来选择上述配置。
