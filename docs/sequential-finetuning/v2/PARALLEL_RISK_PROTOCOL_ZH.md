# 平行题信息能否提前预测旧语失分

在完成的 LoRA Sequential 轨迹上做离线筛查，判断旧语回放样本优先级是否值得利用平行关系。MASSIVE 使用原序与末两语互换的完整轨迹。MTOP 使用原序 DE→FR→ES→HI→TH 和冻结 Single 新序 FR→ES→HI→DE→TH。只读取冻结开发集上的逐题预测。数据来源、每语样本和原始提示沿用已有协议。 [基线设置](PROTOCOL_ZH.md) · [输入提示](PROMPTS_ZH.md)

对任意已经学过的旧语与随后一门新语，仅保留阶段前旧语整句匹配正确，且新旧同源题的意图和槽位标签多重集相同的源题。后续仍用冻结评测程序。因变量是新语训练后，旧语同一题是否由正确变错，输出无法解析也计为变错。特征仅使用该阶段更新前可以观察的信息。

| 条件 | 提供给同一逻辑回归的特征 |
| --- | --- |
| 旧语历史 | 旧语 Base、本语刚学完时的完全正确和合法状态，旧语既有阶段的正确率和合法率，本语训练距今的阶段数、当前阶段之前的总阶段数、旧语评测输入的词元数和槽位数 |
| 同源平行 | 上述特征加新语侧四项，即 Base 和更新前各自的完全正确与合法状态 |
| 异源平行 | 四项新语特征在同轨迹、语言对、标签签名和源 ID 分区内部打乱，旧语行与旧语特征保持原样 |

源 ID 用 SHA-256 确定性分区，余数 0–2 为拟合数据，其余为验证。同一基准分别用一条课程拟合、另一条验证并反向重复。对每个待验证的新语阶段，从拟合课程排除以该语言为当前训练语的所有行。由此验证源题、训练课程和将到来的语言更新均与用于拟合风险的观测分开。逻辑回归使用固定 L2 和 `C=1`，仅在拟合数据上做标准化，其他取值保持程序冻结。对照的打乱使用种子 42，在训练和验证的 ID 分区各自内部进行。

主指标为按阶段与旧语分桶，排在风险最高约 10% 内的真实失分覆盖率。具体为所有桶入选失分总数除以总失分数。分桶内按照源 ID 的确定性哈希打破风险并列。辅指标为逐题平均对数损失、失分平均精确率和同预算内的失分比例。用 5,000 次按原始源 ID 的配对重采样估计覆盖率差及对数损失差的区间，复用同一 ID 对应的各语言对与两个课程结果。区间以验证项风险排序固定为条件，包含题目波动。验证结果仅用于决定该预测信号是否值得进入下一轮随机回放训练。
