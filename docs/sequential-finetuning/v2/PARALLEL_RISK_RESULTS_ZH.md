# 同源信息预测旧语失分的开发集结果

MASSIVE 与 MTOP 各比较两条已完成的 LoRA Sequential 课程。使用另一条课程中独立源题和其他新语更新的数据拟合，然后预测一门未见更新语言到来时，哪些当前答对的旧语题会答错。因变量是原任务的整句完全匹配由对变错。三个模型均为固定超参数的逻辑回归，只改变是否提供同源或同标签异源的新语学前表现。详细协议列出全部特征、数据划分、评测提示及所用的检查点。 [冻结诊断协议](PARALLEL_RISK_PROTOCOL_ZH.md)

每个评估轨迹×更新阶段×旧语分组选择约 10% 的高风险题。失分覆盖率的分母是该基准验证样本内的全部真实失分行，入选失分率的分母是所选行。每个源题可以在多语、多阶段重复。比较区间按源 ID 共同重采样，固定已拟合的风险分数。对数损失越低越好，平均精确率越高越好。

旧语历史已经能在大约十分之一的样本里找到 MASSIVE 28.00%、MTOP 18.50% 的失分。加入同源关系后，MTOP 的整体概率预测改善，固定 10% 预算只多命中 4 例，区间跨零。MASSIVE 两组同样命中 285 例。此前直接比较同源与同标签异源 Replay 也未见稳定的终点益处。此处只验证现有特征可预测的旧语风险，范围是各阶段前已答对、标签相同的平行开发题。回放真正训练之后的因果收益仍由独立的随机化等预算训练验证。 [逐组指标](PARALLEL_RISK_METRICS.csv) · [配对区间](PARALLEL_RISK_CONTRASTS.csv) · [分语言对计数](PARALLEL_RISK_BY_PAIR.csv)
