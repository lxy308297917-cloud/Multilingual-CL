# 检查输出后回退到底座的配对诊断

用已有 FLORES-200 零例、英文标题的输出，比较模型原始续写、底座续写与有条件的回退。样本仍是同一批 80 个独立文档的共享源题和 DE、AR、VI、SW、UR 五个目标语。沿用贪婪解码、停止符、最大长度、提示原文和 GlotLID 权重。此实验从已完成输出中重组候选，计算在该设定下实现回退需要的备用生成次数。 [实际提示与输入清单](FLORES_PROBE_PROTOCOL_ZH.md)

| 策略 | 返回旧语／新语微调终点输出的条件 |
| --- | --- |
| 直出 | 总是返回当前顺序模型的续写 |
| 底座 | 每次均返回原始 Qwen3-4B Base 的续写 |
| 语言检测后回退 | 按此前冻结的 GlotLID 分类规则确认主导语言是所要求目标，其他情况返回底座续写 |
| 语言与质量标记后回退 | 通过上一个条件，同时排除到达长度上限、复制半数以上源文四词组、任一四词组重复三次、槽位格式残余 |
| 随机回退 | 对应前两种回退，每语调用底座的次数完全相同，在同语的 80 题中随机挑题，重复 1,000 次 |

语言检测与质量标记沿用此前诊断规则，决策不读金标译文。按同题计算各语言的语料级 chrF++、目标语判定率和两次生成需求比，宏平均为五语等权。用 5,000 次同源配对重采样比较回退策略与直出、底座的 chrF++。另报告固定次数随机回退的平均 chrF++，判断同一备用生成预算下哪类题值得回退。已知 GlotLID 对短句、阿语的覆盖偏低，目标语率用于诊断，只在直接翻译质量与备用计算次数的联合证据支持时采用回退。 [检测器校验](FLORES_LANGUAGE_RESULTS_ZH.md) · [质量标记定义](FLORES_FEWSHOT_RESULTS_ZH.md)
