# 多语言顺序微调的研究切入点

建议把论文的主问题定为 **顺序微调损害了哪一部分能力，以及什么样的平行信号能保住这部分能力**。先用等预算的基线定位损失，再利用同源、多答案的条件对照，把共享的任务能力、目标语言选择和输出格式拆开测量。

## 初步证据

**学习率与输出形式会改变对遗忘的解释。** MASSIVE 原序全参的官方槽位 F1 从 5e−5 的 28.41% 升到 1e−5 的 62.66%，对应的 1e−5 Joint 为 63.87%。在 LoRA 中，原序的两个种子都观察到小幅 Replay 终点收益。MasakhaNER 新课程中，Replay 的 BWT 改善 1.20 个百分点，却只将官方终点提高 0.50 个百分点，终点差的区间跨零。IBO 的后续损失在两个检查点都能解析的题上仍有约 5 个百分点。不同现象需要分别对照学习率、输出合法性和逐语分数。 [V2 官测与配对结果](RESULTS_ZH.md) · [两种子历史复核](CL_HISTORICAL_ZH.md)

**MasakhaNER 的压力全参同时改变学前转移、本语增量与保留。** 五个本语阶段的官测增益均为正，四个有后续阶段的语言均出现显著损失。全参比 LoRA 的平均本语增量大 6.33 个百分点 [+5.25, +7.44]，而本语学完的平均绝对 F1 低 1.34 [−2.22, −0.49]。全参 FWT 比 LoRA 低 9.60 个百分点，较低的学前起点扩大了阶段内差值。比较时均限制为各语学完及最终两次都能合法解析的题，SWA、LUG、IBO、YOR 的终点损失仍分别为 10.88、10.30、10.82、14.31 个百分点。此处全参为 5e−5 单种子，较低学习率的复测在 MASSIVE 上已验证。 [全参官测热力图](figures/ner-MasakhaNER-2.0-Full-FT-Sequential--新课程-test.png) · [配对基线](MATCHED_COMPARISONS_ZH.md) · [合法子集](V2_COMMON_VALID.csv)

**MasakhaNER 全参 Replay 的终点收益集中在部分语言。** Replay 用等量旧语词元替换该阶段部分本语训练词元。正式测试 AP 从 57.89 升到 61.22，同题配对差 +3.33 个百分点 [2.43, 4.20]。BWT 增加 12.51 [11.21, 13.83]，平均本语增益减少 4.47 [3.34, 5.67]。IBO 在本语阶段后由 50.52 升到终点 67.62，对整体 BWT 的转正贡献最大。SWA 和 YOR 到终点仍分别损失 5.41 和 5.76 个百分点，HAU 的当阶段增益为 −0.18 [−2.37, +1.89]。报告两种 BWT 及每语习得，才能看出一个语言的后续增长如何抵消其他语言损失。 [全参 Replay 官测热力图](figures/ner-MasakhaNER-2.0-Full-FT-Replay--新课程-test.png) · [配对差及各语指标](RESULTS_ZH.md)

限制为终点两组都能合法解析的题时，Replay 相对 Sequential 的 SWA、LUG、IBO、YOR 终点 F1 仍分别增加 6.43、7.34、8.82、6.42 个百分点。HAU 在 1,595 道共同有效题上仍下降 8.44 个百分点 [−10.17, −6.72]。这些是每语各自的共同有效子集。 [终点配对数据](V2_COMMON_VALID_METHODS.csv)

**语言平均数会掩盖习得与保留之间的取舍。** MTOP 新序 LoRA Replay 的官方测试 AP 从 59.71% 升至 61.39%，BWT 增加 2.30 个百分点 [1.63, 2.94]。五语平均习得差为 −0.10 [−0.59, +0.41]，其中 DE 的习得下降 2.47 [−3.72, −1.22]，TH 的习得提高 1.61 [+0.18, +3.02]。HI 和 DE 从各自学完到最终的损失分别少了 3.02 和 2.51 个百分点。后续方法应同时报告逐语习得和逐语保留，才能判断回放预算花在哪些语言上。 [同题配对对照](MATCHED_COMPARISONS_ZH.md) · [逐语数据](V2_METHOD_PAIRS.csv)

**MTOP 全参 Replay 提高了终点平均分，效果随语言而异。** 正式测试 AP 从 50.57 升到 56.07，配对差 +5.49 个百分点 [4.66, 6.32]。BWT 从 −4.32 升到 +2.10，平均本语习得减少 2.49 [1.74, 3.23]。HI 的本语学完分数由 52.20 降为 44.88，后续损失由 9.19 减为 2.25，终点分别为 43.02 和 42.63。FR 的终点增加 11.19 个百分点，TH 的终点下降 1.58 个百分点。HI 的损失缩小与本语学完时的起点降低同时发生。 [全参 Replay 官测热力图](figures/mtop-MTOP-Full-FT-Replay--新课程-test.png) · [逐语配对数据](V2_METHOD_PAIRS.csv)

例如 MASSIVE 原序 LoRA 在 SW → UR 时，502 道合格同源题中有 58 道同现，随机重配的期望为 71.94，差为 −2.78 个百分点。进一步按其他三种语言在更新前的可观测数与答对数匹配后，整体差减弱。该敏感性分析在看到初次结果后加入。初筛条件会改变样本构成，长度、词汇和跨语言共享难度也可能产生关联。统计描述支持重新审视「把当前语同一条题的译文优先放回，就能命中正在遗忘的旧语题」这一选样规则。此前一条 125 步同预算试验中，同源组相对同标签异源组的 SW 槽位 F1 为 −0.30 个百分点，区间为 [−1.29, +0.69]。 早期平行回放实测

**输出失败的方向需要直接观察。** 在 80 个 FLORES-200 开发源句上，要求相同英文输入译成 DE、AR、VI、SW、UR。交换高学习率 Full-FT 的末语 SW 与 UR 时，其他三种目标的输出主导语言无可观测的相应交换。两条高学习率轨迹的平均 chrF++ 为 4.31 和 5.27，Base 为 38.46，LoRA 两条约为 38.4。检查样例可见英文源句片段、循环复述指令和槽位输出的残余括号。1e−5 全参的本地语言答题标题带来 +1.96 chrF++，95% 配对区间 [+1.09, +2.98]。GlotLID 在这批阿语金标只通过 41/80，语言百分比应按语校验，翻译质量仍以 chrF++ 为主。此处是结构化任务训练后的迁移诊断，无法推断自然语言生成任务依序学习时的末语效应。 [逐语诊断与热力图](FLORES_LANGUAGE_RESULTS_ZH.md)

**末语相关变化可以局限在字词。** 对要求 DE、VI 的 160 份标准前缀回答，高学习率 UR 终点有 29.38% 含至少两个阿拉伯字母，交换末语的 SW 终点为 0%，同源配对差区间 [+20.63, +38.75] 个百分点。这个 Unicode 脚本由多语共享，标记叫脚本混入。两例提示把 UR 终点的 chrF++ 从 4.31 提到 4.76，混入脚本的回答比例达到 54.38%。格式指令单独不足以恢复原始翻译质量。 [脚本与候选评分](FLORES_CANDIDATE_ZH.md) · [两例提示配对结果](FLORES_FEWSHOT_RESULTS_ZH.md)

**候选内容读出和目标语言读出可分离。** 固定同一种语言，用两道题交换候选译文。5e−5 全参 UR 终点在 DE、AR、VI 三语均得到 40/40 正内容交互，SW 为 32/40，UR 为 38/40。再固定同一个意思，只交换 SW 与 UR 翻译要求及候选，Base 为 80/80 正语言交互，UR 终点为 39/80，平均交互 −0.01，区间 [−0.03, +0.01]。SW 终点为 64/80，平均交互仅 +0.06，Base 为 +2.51。1e−5 UR 终点有 80/80 正交互，均值 +1.84。这是对内容和语言要求的候选诊断，翻译生成质量仍按原始输出评分。 [四格候选对照](FLORES_CANDIDATE_ZH.md)

**回答通过语种检测之后，仍需检查内容质量。** 直接复用相同提示已生成的续写，按主导语言与重复、复制、截断和槽位残余标记决定是否调用底座替换。两个 LoRA 终点分别回退 28.50% 和 26.75% 的回答，五语 chrF++ 比底座高 0.81 [+0.33, +1.34] 和 0.61 [+0.09, +1.16]，也高于同调用预算的随机回退。1e−5 全参从 29.27 增至 35.34，仍比底座 38.46 低。5e−5 全参检查后每题均回退。作为未来方法的推理对照，它量出了用备用模型能补回多少，与模型自身能否学会输出目标语的研究问题相互补充。 [协议与逐语回退结果](FLORES_FALLBACK_RESULTS_ZH.md)

## 可检验的训练方法

第一项候选是 **用平行答案训练模型对指定输出语言的响应**。同一源句 `x` 有等义译文 `yₐ` 与 `yᵦ`。用只替换目标语言的两条指令 `a` 与 `b`，得到一个四格交叉对照。`s(x, a, y)` 是给定这条指令的目标内容平均对数似然。交互量为 `s(x,a,yₐ) − s(x,a,yᵦ) − s(x,b,yₐ) + s(x,b,yᵦ)`。如果模型只是整体偏向某类译文，其固定偏好会在交叉差中抵消。训练候选是在通常 SFT 与固定预算 Replay 上加入交互排序损失，同时保留两个方向的单独边际。如果单向边际失衡，继续追查目标语词元长度和任务模板的影响。

给定相同底座、序列和训练数据，比较普通顺序、普通回放、同一批平行样本的常规 SFT、真配对交互损失，以及同语言和长度层内打乱源题配对的交互损失。真配对与打乱组读取相同样本，相同有效批次，且计算等量额外前向。由未训练进入缓冲区的旧语译文产生的额外数据覆盖，需与同量异源旧语译文对照。报告目标语率、跨语误答及 chrF++，同时报告当前语言习得、旧语言 F1/BWT 和通用生成检查。若真配对只改善语言检测，或匹配打乱组同幅改善，证据支持语言曝光或形式变化，仍需验证内容和配对的贡献。

**32 步等预算预试验已完成。** 它以严重退化的 5e−5 全参 UR 终点为起点，用训练集内 256 个新平行源题做三组 LoRA 修复。普通 SFT 将开发集平均目标语率提高 16.25 个百分点，平均 chrF++ 变化为 −0.36，区间 [−0.78, +0.03]。真配对减打乱的 chrF++ 为 −0.03 [−0.33, +0.16]，保留的五语 MASSIVE 槽位 F1 差为 +0.32 [−0.34, +1.23]。强压力起点的输出质量接近地板，本轮只有一个种子与短训练。在裁定方法前，应先在正常学习率和有可测生成余量的顺序轨迹中重复，预先设定同时改善旧语表现及目标语言质量的判据。 [训练方案](TRANSLATION_REPAIR_PROTOCOL_ZH.md) · [同预算结果](TRANSLATION_REPAIR_RESULTS_ZH.md)

在持续学习场景中，可以把固定的交互目标替换为**旧检查点的条件交互记忆**。旧语阶段完成后，在回放缓冲区保存少量平行源题的交互量与两项单向边际。下一语更新时，只惩罚这些旧语交互量下滑，同时保留当前语的常规 SFT。候选损失是 `SFT + λ · max(0, m旧 − m当前)²`，其中 `m` 为四格交互。在弱语言的旧检查点未显示语言区分时，不给该题设置正交互目标。和同样数据的普通 Replay、固定边际损失和打乱旧检查点目标比较，另测试只蒸馏目标答案似然能否得到相同结果。每组前向与输入词元匹配，记忆开销是每源题的三个标量和样本自身。把监督施加在阶段间下降的条件响应上，是这个候选相对单次语言对齐的研究假设。现有三臂试验只测了固定边际，阶段间记忆尚无实测。

第二项候选是 **先估计旧语样本的风险，再决定平行回放用在哪里**。从旧语记忆中抽取少量不进测试的诊断题，用一个固定短更新测其旧语损失趋势。对照只用旧语历史难度的采样法，测试加入同源异语上的学前差异能否预测旧语回落，再在同等训练预算下评估选出的缓冲区。先要求风险分数在新语言转移和新文档上有增量预测力。诊断题选择与最终官测隔离。

**平行信号的第一道离线筛查已做。** 交叉留出源 ID、课程和下一训练语时，在 10% 的风险筛选预算下，同源信号相对旧语历史在 MASSIVE 上多覆盖 +0.00 [−1.81, +1.68] 个百分点的真实失分，在 MTOP 上是 +0.33 [−1.57, +2.27]。MTOP 同源相对异源的对数损失降低 0.005，但最可能遗忘题的覆盖区间跨零。现有证据支持用平行样本做机制诊断，基于当前特征做回放排序的收益仍待验证。 [留出预测协议](PARALLEL_RISK_PROTOCOL_ZH.md) · [风险筛查结果](PARALLEL_RISK_RESULTS_ZH.md)

可以优先把 **受提示和学习率影响的输出退化** 做成实证发现。若在明确自然语言输出的课程上也能测得随末语切换的错语增加，就有理由测试上面的平行答案交互。若主要现象仍是图式复述、原句复制或重复，先用任务格式对照和低学习率复现实验确认，避免把它们归为统一的语言遗忘机制。最终以两种顺序、至少两个训练种子和独立生成数据检验迁移。
