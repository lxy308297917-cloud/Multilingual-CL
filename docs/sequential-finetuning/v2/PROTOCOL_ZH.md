# 多语言持续学习 Benchmark V2

使用 Qwen3-4B Base，在冻结的同语言题组上测量直接习得、未见语言的迁移、旧语言的后续变化，以及相同训练预算下 LoRA 和全参微调的差异。每条顺序轨迹都评到阶段×语言矩阵。训练顺序由既有方案或固定开发集 Single 分数决定，官方测试用于确认已经冻结的顺序与方法。

## 更新参数及预算

六个条件用 LoRA 或完整参数各搭配 Sequential、Replay、Joint。Sequential 每阶段使用该语言原定顺序。Replay 用 1,000 条历史样本缓存，缓存只包含前阶段确实训练过的样本，约 10% 旧语言输入词元逐位置替换当前语言样本。替换要求总长度和监督起点同时相同。Joint 从 Base 初始化，打乱相同预算的多语原始题，仅保留终点作离线参照。Single 每语从 Base 独立初始化并执行本语阶段的预算与暖启动。首语满足数据、顺序、种子、优化器初态都一致时共享检查点，并核对模型权重、优化器状态和数据身份。

全参采用四张 RTX 3090 上的 FSDP，FP32 主参数与 AdamW 状态、BF16 前后向、FP32 梯度归约、梯度检查点及全局梯度裁剪 1。LoRA 底座 BF16，七个 Attention／MLP 投影使用 FP32 适配器，rank 16、alpha 32、无 dropout 和附加 bias。两种训练的有效批量都是 16。MASSIVE 和 NER 的微批 4。MTOP 微批 2，LoRA 累积 8 次、四卡全参每卡累积 2 次。阶段间持续继承参数、AdamW 状态和训练步数，整条轨迹只在起始 16 步线性预热。主压力条件的峰值学习率为 5e−5。MASSIVE 另保存或补做同方案的 1e−5 全参 Sequential、Joint 和 Single。GPU 时间、实际输入及监督词元与峰值保留显存见回执。

## 持续学习指标

设第 `i` 个训练语在阶段 `t` 的评分为 `A[t,i]`，`A[0,i]` 为 Base。AP 为终点对全语等权平均，单位是百分数。其余为同语言的百分点差。

- **BWT** 对非末语求 `A[T,i] − A[i,i]` 均值，报告最终反向变化。
- **FWT** 对第 2 到第 T 语求 `A[i−1,i] − A[0,i]` 均值，报告本语训练前相对 Base 的变化。
- **习得** 对全部语言求 `A[i,i] − A[i−1,i]` 均值。
- **遗忘** 对非末语求学完本语之后的最高评分减终点。
- **Negative BWT** 对非末语求 `max(0,A[i,i] − A[T,i])` 均值，正值表示未被其他语言增益抵消的终点损失。Positive BWT 对相反方向取同样的截断和分母。
- 习得明确指 95% 配对区间下界大于 0。后续明确下降指至少一个后续阶段与学完本语时的比较上界小于 0。同语言的多阶段比较按后续阶段数校正，末语只进习得分母。

根据 5,000 次同题重采样计算正式样本区间。MASSIVE 与 MTOP 使用共享来源题号，XNLI 使用共同前提组，TyDiQA 用同语标题组，MasakhaNER 用同语句子。重采样的每次抽取在同一方法或对照的所有检查点上保持一致。微 F1 为 `2TP/(2TP+FP+FN)`，每次重采样均重新累计计数。比较同时保存 95% 题目区间和训练种子身份，分别表征两类变异。Joint 和 Single 的终点分数可比较，时序指标只在完整的顺序矩阵上计算。

阶段矩阵与 BWT 沿用 GEM 的计算结构。此处的 FWT 把未微调的 Qwen3-4B Base 作为起点，计量其他语言阶段相对同一预训练模型带来的增益。Winata 等人在 MASSIVE 槽位任务也采用语言接续，比较了回放、离线多语训练与分阶段学习率。这里按冻结 Qwen3 配方比较 LoRA 和全参，并为两个学习率保留各自的对照。 [GEM 公式 2–4](https://proceedings.neurips.cc/paper/2017/file/f87522788a2be2d171666752f97ddebb-Paper.pdf) · [Winata 等人的多语持续学习实验](https://aclanthology.org/2023.findings-acl.48/)

MasakhaNER 的首语 SWA 复用了 Single 的训练权重。新阶段批次在另一张 RTX 3090 上重测，训练回执、评估题身份、推理配置与评分器均相同。开发 384 题中有 10 道生成字符串发生变化，微 F1 从 69.30% 到 69.54%，同题差为 +0.24 个百分点，95% 区间为 [−0.57, +1.34]。官方测试中 60/1,883 道生成字符串发生变化，微 F1 从 72.71% 到 72.88%，同题差为 +0.17 个百分点，区间为 [−0.11, +0.44]。阶段矩阵使用新批次记录，课程排序保留冻结时的旧 Single 记录。题目区间单独计量抽样误差，推理重跑波动和训练种子波动需分别考察。
