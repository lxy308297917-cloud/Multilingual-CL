## 固定训练与评测

保持Qwen2.5-1.5B-Instruct、Aya80%+双向翻译各10%输入Token配方、4293步/1,536,351主输入Token、599,469主监督Token、正式42465步学习率日程的同一前缀、BF16权重及AdamW动量。隐藏状态索引10、内容Token均值池化、固定Base英语2000候选、温度0.07、每4步8对、辅助microbatch4全部不变。训练算术仅把辅助反向的0.1替换为固定系数；[可逆代码差异验核](ENGINE_IDENTITY.json)与[完整差异](ENGINE_DIFF.patch)保留。

终点共生成512条回答：SW阅读64、英语阅读64、双向翻译各128、英语指令128。阅读采用上一轮验收后的内容评分，格式另报；已知1道英语源题结构错误在本轮D1出分前排除计分，保留全部64条原始输出和原批次，英语有效分母63。数学评分不可靠，本轮完全排除。B/D0及Base的匹配缓存经输入、模型、配置和逐题评分核验复用；不把旧协议或旧自动数学零分混入。见[评测清单](EVALUATION_DATA_FROZEN.json)、[缓存凭证](EVALUATION_REUSE_VERIFIED.json)。

表示诊断只用原独立1000对，固定第10层，不扫描层位。分别报告固定Base英语目标和当前EN/SW的双向检索、正负配对差与表示方差；InfoNCE训练损失本身不作为有效性结论。

[冻结协议](PROTOCOL_FROZEN.json)规定：EN→SW chrF++相对B的配对95%区间下界须大于0；SW阅读下界不低于B−2点，SW→EN不低于B−1点，英语阅读与指令分别不低于B−2点。独立固定锚点检索与正负配对差也须相对D0有区间支持的改善。使用10000次来源分组配对bootstrap、seed42。样本小、区间宽时报告不确定；英语保持仅指这些任务相对B的结果。

不看中间任务分数选checkpoint，不加系数/温度/池化/层位扫描。未超过B或只改善表示指标就结束这个固定原型；通过全部门槛也只允许讨论第二seed，不自动扩展。

新增预算上限 **6.75 GPU小时**，其中D1训练上限3小时；账号合计最多4张GPU。原D0实际训练约83分钟，当前吞吐预检支持约72分钟（不含全部加载、检查点和后续评测开销），时间为估计。所有模型与原始逐题输出留在服务器，公开仅代码、协议和聚合结果。
