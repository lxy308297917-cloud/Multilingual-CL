## 方法身份与证据边界

| 方法 | 当前结论 | 限制 |
|---|---|---|
| Dense FFT | 独立函数式 AdamW 递推保留运算顺序，CPU BF16/FP32各20步权重和m/v逐位一致 | 小矩阵验证，不能代替整模型训练与完整恢复验收 |
| HFT15 | 同上；当前为历史整矩阵约15%预算变体 | 不等于原论文50%参数设置，不应只写原版HFT |
| MoFO | 保存的官方代码CPU40步：BF16权重和mask一致；FP32权重最大差1.49e-8，m最大差2.38e-7 | 动量mul/add与lerp及更新表达式顺序有差异，不能声称状态逐位复现官方 |
| SSU | 当前Token加权变体与保存的参考样本等权实现有实质选参差异 | 冻结源代码可复现不等于参考方法复现；当前选择和checkpoint原样保留 |
| Element/Protected | 本轮正式训练仍排队；不能将预检通过写成完整预算完成 | 完整终点、实际更新和正式评测待验收 |

Dense/HFT另保留代数重排公式对照：BF16权重相同、FP32最大差2.86e-6。补充保持运算顺序的独立函数式递推后，四种方法/精度组合的20步权重和m/v均逐位一致。两项证据分开保存，不把重排误差隐去。

## SSU同材料实测

同一Base、同一128条校准材料，仅收集一次激活充分统计；长度42—625 Token。原Token加权FP32实现的196个矩阵选择均被缓存完整复现。

固定相同列名额和FP32评分，仅改为样本等权：

| 范围 | 入选元素重合率 |
|---|---:|
| 全体 | 89.2484% |
| Attention | 93.6128% |
| MLP | 88.6652% |

21,138,432个原入选元素被替换，占原名额10.7516%，196个矩阵均改变。FP32与FP64评分得到完全相同选择，主要差异不能归为浮点噪声。

参考BF16评分在156个矩阵的边界存在并列；使用真实CUDA top-high complement、保持同列名额时，与当前选择重合89.1966%。它与稳定并列处理的同BF16评分选择重合98.6943%。聚合影响、精度影响、并列处理影响分别记录，不能相互替代。

当前实现符合冻结源码，但未找到预先说明Token加权及评分精度修改的设计依据。当前行应明确标成 **SSU-token-weighted预算变体**。没有中途替换mask，也没有排入额外修正版训练；若最终表需声称严格参考SSU，还需要单独解决该方法身份问题。

## MoFO优化与测量

独立实现位于 `code/mofo_deferred.py`，冻结 `../code/optimizer.py` 未修改。

保留每步重新选mask、官方阈值全部并列、FP32动量、BF16权重、原weight decay范围和写回顺序。优化将union留在GPU，标量汇总后集中读回，sqrt/div只计算入选坐标；不减少实际位移、非零写回或union统计。

CPU40步以及四个真实Qwen矩阵形状的CUDA对照，逐步权重、m/v、mask、union和统计均一致；额外覆盖并列、零学习率、刷新边界和状态序列化。这是对冻结本地实现的等价证据，不能扩大成对官方源码状态逐位等价。

共享本账号HFT显卡空余显存的短时同步profiling显示，大MLP矩阵的CPU union更新与索引传输耗时突出：gate约47ms、down约58ms；单矩阵候选实现实测更快。这些时间受共享上下文和同步测量影响，不作为全模型提速倍数。完整196矩阵每步索引CPU传输约1.46GiB，优化后集中标量读回约8KB，union的checkpoint传输仍保留。
