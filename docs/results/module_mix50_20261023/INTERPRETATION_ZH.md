# 一页结论：Mix50与Attention优势是否值得继续

**四份真实短训和全部可执行评测已完成。本轮没有得到值得扩大规模的新方案，建议停止当前静态Mix50配方及“Attention-only全面更好”的扩展；不自动追加训练。**

新增LR077-s43、Attn-s43、Mix50-s42、Mix50-s43，每份4293步；复用原seed42模型。共同样本、Token、batch和学习率日程前缀固定。Mix50与同顺序LR077只改变模块名额分配：总名额77,070,336中Attention与MLP各占38,535,168。整轮完成4096条新回答、8份正式可恢复checkpoint，持卡上下文成本9.8535 GPU小时，上限16。

**1．50/50分配没有稳定超过合理基线。**

旧开发集的Mix50−LR077：

|训练顺序|EN→SW chrF++|SW阅读F1|英语指令strict百分点|
|---|---:|---:|---:|
|seed42|−3.507|−2.030|+3.125|
|seed43|−0.496|+2.979|−2.344|

两顺序平均EN→SW差值为−2.002，来源同步配对95%区间[−2.896,−1.118]，在这些固定模型和旧题上有下降证据。新SW阅读差值分别−5.070、+0.446，均不足以证明可靠提升；seed42点估计未守住原定−2 F1容忍边界，但区间较宽，不能把它说成确定损伤。新英语阅读及指令也未显示全面、稳定的保持优势。详见[分开的完整结果](README_ZH.md)。

**2．Attention先前两个优势没有在第二种顺序的旧题上复现。**

相对LR077，seed42的EN→SW/英语指令优势为+4.070/+7.031；seed43变为−1.107/−0.781。seed43区间包含0，因此是正向优势未复现，不是证明Attention必然更差。新指令题上Attention仍有局部积极信号（两顺序点估计+3.125/+5.469，后者区间大于0），但其他任务及相对Base的英语损伤不支持全面保持结论。

**3．一个加强提示没有消除seed42的翻译差距。**

固定64题上Attention−LR077由4.173变为4.539 chrF++；差距变化+0.365，配对95%区间[−1.987,+2.820]，没有证据表明差距明显缩小。LR077被检测为SW的回答仅从24/64变为30/64；Base从43/64变为63/64。提示确实影响部分模型的语言行为，但不能把全部方法差异归结为一句提示。新提示同时改用英语指令并增加输出限制，无法区分这两项各自的作用；Mix50未参与这项提示诊断，不能据此宣称Mix50提示稳健。

**4．更值得保留的是训练顺序敏感性。**

同一LR077配方，新SW阅读从seed42的23.102变为seed43的8.007；累计实际更新路径却仅从186.938变为186.861。Attn两顺序路径也很接近。它说明单一总路径指标不能充分描述功能变化；两个训练顺序不足以估计随机性总体，更不能按开发成绩挑最好顺序。

**5．新翻译确认缺失，原升级规则不可完整验收。**

严格排除跨语言共同原文档的历史开发池、训练及近重复后，FLORES dev仅剩1个可用文档，不足128。新确认只含SW阅读64、EN阅读64、英语指令128；未替换题源或运行正式测试。历史池包含相同英语原句不等于当前模型训练泄漏，详见[AUDIT_CLARIFICATION.json](AUDIT_CLARIFICATION.json)。本轮已见结果不支持扩大Mix50，同时也不能把旧翻译题包装成新确认。

**后续决定：结束本轮固定原型，保留代码、权重、逐题输出和负结果。若重新立项，先解决验证材料与顺序稳定性问题，不直接叠加子空间、层选择或比例扫描。这里停止的是当前配方，不是否定全部多语言稀疏微调。**
