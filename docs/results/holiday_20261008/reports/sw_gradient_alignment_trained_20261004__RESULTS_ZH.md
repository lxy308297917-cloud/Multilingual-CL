# 已训练模型的 SW／英语梯度方向只读复测结果

两个已训练模型与 Base 使用相同冻结的 96 条训练侧开发样本和相同的 56 组逐模块方向算法。两项 `DONE.json` 的模型权重 SHA256、输入哈希、`ALIGNMENT.json` 与 `STABILITY.json` 链条均核验通过；队列已结束，GPU 已释放。原始逐组数值在各子目录。两个已训练模型的预算不同，**这里只诊断方向变化，不作同预算效果比较或因果归因**。

|模型|EN→SW／英语余弦中位数|负余弦组|分半 Spearman（层区组95%区间）|SW→EN／英语余弦中位数|负余弦组|分半 Spearman（层区组95%区间）|
|---|---:|---:|---|---:|---:|---|
|Base|+0.051|3/56|0.692 [0.501,0.834]|+0.070|0/56|0.567 [0.250,0.795]|
|完整方案一 15% `element_protected`|-0.005|38/56|0.010 [-0.314,0.336]|+0.003|19/56|0.191 [-0.116,0.472]|
|完整均匀 5.798% `uniform_protected`|+0.005|18/56|-0.132 [-0.415,0.160]|约 0.000|29/56|0.266 [-0.038,0.530]|

训练后有更多组呈弱负方向，但其余弦通常**非常接近零**。同一算法下，EN→SW 模块平均梯度范数中位数从 Base 约 4.15 降至方案一约 0.59、均匀组约 0.72；SW→EN 从约 5.62 降至约 0.90／1.05。训练后分半余弦排序区间都跨零；例如方案一 EN→SW／英语只有 20/56 组在两半都为负，远少于全体均值的 38/56 组。因此不能把负余弦计数上升直接解释为稳定的英语冲突机制，也不能凭它指定稀疏更新或投影层。

现有固定正式测评确有任务取舍：方案一相对 Base 提升双向 SW 翻译，但 IFEval/GSM8K 下降；这些**输出结果与本方向变化同时出现，不足以证明方向变化造成能力下降**。当前“按模块梯度方向冲突投影更新”的前置定位证据未通过稳定性要求，停止据此安排正式训练。若未来重新研究，需在训练途中而非仅 Base／最终模型上取得方向时间序列，并在独立同预算短训中验证训练规则；正式测试集不能用于调投影阈值。
