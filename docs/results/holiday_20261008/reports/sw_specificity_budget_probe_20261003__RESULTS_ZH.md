## 可比性

`specificity_protected`、`lp_protected`、`uniform_protected` 都从相同 Qwen2.5-1.5B-Instruct Base 独立训练，使用 seed43 顺序的同一前 2048 步、1,405,225 个输入 token、相同的 FP32 Adam／BF16／cosine／英语保护机制，并每步精确选择 75,969,304 个候选元素。新方法按冻结 Base 的 EN→SW/英语梯度能量比率连续分配模块名额，同时约束 SW→EN 和 Aya 代理覆盖不低于均匀组；详见 `README_ZH.md` 与冻结选择表。它不是已经证实的更新收益估计。

开发测评使用一批**此前未使用**的 128 条 D2 EN→SW 开发句，排除了此前 464 个开发样本 ID 及正式测试源重叠。三组使用相同贪心生成参数；详细输入、每例预测及分数见 `eval/manifest.json`、`eval/PER_SAMPLE.jsonl`、`eval/RESULTS.json`。正式测试集没有用于此次预算选择或评估。

新方法相对旧 LP 的逐例 chrF++ 平均差为 **+4.36**，配对 bootstrap 描述性 95% 区间 **[+3.21,+5.58]**，91 例较好、37 例较差。相对强均匀组的平均差仅 **+0.68**，区间 **[-0.22,+1.58]**，71 例较好、56 例较差（1 例持平）；其 corpus chrF++ 高 0.93。这是短训下的小幅信号，未达到事先冻结的“相对均匀逐例区间下界大于 0”门槛。不能据此声称强基线以上的可靠收益，也不能推断完整训练会保留优势。新方法与均匀组都启用了全部 196 个候选矩阵，训练峰值显存近 20 GiB；旧 LP 的活跃矩阵较少，耗时和显存更低。因此即使有微弱分数优势，也需计入资源代价。

逐例最差的五条相对均匀差异为 -23.30、-11.17、-10.53、-9.23、-9.03 chrF++；最好的五条为 +10.38、+11.70、+12.24、+13.59、+16.51。正负例都有，不能按少数例子宣称机制。下一步停止基于同一开发集调此预算；如要继续探索，先提出不同且独立可检验的训练假设，并保持正式下游任务与英文能力保留优先。
