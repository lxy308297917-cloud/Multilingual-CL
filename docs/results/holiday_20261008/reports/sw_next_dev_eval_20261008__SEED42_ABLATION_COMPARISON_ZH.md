翻译／摘要表中的分数是 corpus chrF++，逐样本区间对应逐句 chrF++ 平均差，二者聚合量不同。英语数学严格 `####` 输出格式存在严重代理失真，只作诊断；SW 阅读没有独立同任务开发题。翻译切片来自原 D2 dev 池，旧训练曾计算其验证损失，不是完全盲测。区间只描述固定样本和模型，不覆盖训练顺序不确定性或多任务比较。

原始生成、评分及 SHA256 收据路径见 `SEED42_ABLATION_COMPARISON.json`；正式测试不因本开发分析重跑或改协议。

只读复核：新补测的 seed42 去保护版 256 条英语指令输出使用同一检查器并固定 `langdetect` seed 0 重算后，prompt strict 仍为 14.0625%，约束 strict 仍为 22.6415%，逐题判定变化 0；证据在 `SEED42_UNPROTECTED_INSTRUCTION_AUDIT.json`。其余七模型已在 `INSTRUCTION_SCORING_SENSITIVITY.json` 通过相同检查。本开发集中的指令差异不能归因于已发现的短文本语言检测随机判定。
