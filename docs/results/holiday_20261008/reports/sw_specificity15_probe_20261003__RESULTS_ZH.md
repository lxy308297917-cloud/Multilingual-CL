# 15% 精确同预算连续分配短训结果

**截至 2026-10-04 00:43 CST：两组 2048 步短训及同批双向翻译开发测评均完成，所有训练权重和结果文件哈希核验通过，GPU 已释放。新方法未通过预设筛选门槛，因此没有启动英语后续开发测评或 22,146 步正式训练。**

## 可比性

`specificity15_protected` 与 `uniform15_protected` 均从相同 Base 独立开始，使用 seed43 同一前 2048 个 batch2 步（1,405,225 输入 token）、相同 FP32 Adam／BF16／学习率日程、相同英语敏感度动态保护。两者每步精确选中 **196,529,312 / 1,310,195,712** 个候选元素，与方案一逐矩阵 15% 向下取整后的名额相同。区别仅在 28 层×Attention/MLP 的名额分配：新方法用冻结 Base 的 EN→SW 相对英语梯度能量比率作 KL 先验，并以均匀组为 SW→EN／Aya 代理覆盖和英语风险参照；均匀组每矩阵 q=15%。具体选表、约束、样本顺序和哈希见 `README_ZH.md`、`selection_*.json`、`code/sw_d2_specificity15_probe/TRAINING_RELEASE.json`。

开发测评为此前未使用的 EN→SW、SW→EN 各 128 条 D2 开发句，排除过去 672 个开发 ID 与正式测试源重叠；采用同一贪心生成协议。Base 只读参照分数与同批数据也已保存，但**同预算均匀保护组才是主要比较对象**。完整逐例结果见 `eval/PER_SAMPLE.jsonl`，任务汇总与配对 bootstrap 见 `eval/RESULTS.json`。

这两次相同成本的短训没有给出相对强均匀基线的可靠优势。此前 5.798% 的连续预算短训也只表现出相对旧 LP 的修复，而未稳定超过同预算均匀组。当前证据不支持沿同一梯度比率继续做完整训练；下一步应检验与“模块梯度能量”不同的机制，且先在训练侧开发任务建立独立、可复测的收益证据。
