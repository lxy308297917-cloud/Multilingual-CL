# SW D2 假期阶段研究判断（2026-10-04）

本轮以固定协议下游任务为主，训练侧短训只用于决定是否值得完整训练；PPL/NLL 未用于挑方法。到目前为止，**没有一个新候选同时在同预算对照下显示可信的 SW 双向收益和英语保留**，因此没有启动新的 22,146 步长训或消耗正式测试集。

## 短训日程适用范围（03:30 补充审计）

各 2048 步短训的候选与对照之间使用相同的学习率日程，因此其**短训内部比较有效**；但代码以 `max_steps=2048` 实例化 cosine + 5% warmup，而完整训练是 `max_steps=22146`。Transformers 将 warmup 向上取整，分别为 **103** 与 **1108** 步。2048 步末短训学习率为 0，完整训练同一步约为 **4.9754e-5**；前 2048 步平均学习率分别为 **2.5e-5** 和 **3.6449e-5**。512 步短训同样按 512 步日程生成。这些负向筛选结果不能视作“沿完整训练日程前缀”的证据，尤其不应据此强断某机制在正式日程下一定无效。精确数值、计算公式和源码哈希见 `PILOT_SCHEDULE_AUDIT.json`；冻结的历史代码、权重与原始结果均保留。

## 已完成的正式任务

LP 风险分配 seed43 两项训练与固定正式测评已完成，并与 seed42 及同顺序、同预算均匀组配对。LP 的 EN→SW 正式逐样本均值比均匀组分别低 17.53 和 16.48 chrF++；这是清楚的目标方向退化，不能以 SW 阅读、摘要或部分英语保留的局部提升掩盖。五方法、MoFO15、SSU15 等共 21 个模型的 168 项正式 DONE 已逐一核对，关联 1,407 个产物 SHA256 重算通过。正式测试只用于事后报告，未用于下述新规则调参。证据见 `../sw_rollback_budget_20261002/FINAL_REPORT_ZH.md` 和本目录 `FORMAL_COMPLETION_AUDIT.json`。

强基线的动态掩码在初始十次重选中每次换入约三分之二的入选元素；完全冻结和平滑 EMA 都减少最终 BF16 差异数，但这两种控制在短程双向翻译上都未胜过原动态组。这说明下一步不能仅以“减小换入率”作为方法目标；如果未来提出任务条件化或代价约束的换入规则，需要先找到独立、可复测的目标收益信号及新的开发样本。英语小样本的正向题数差属于线索，不能代替正式 IFEval/GSM8K，亦不足以豁免双语门槛。

补充的只读逐例审计 `MASK_DEV_ERROR_AUDIT.json` 将每个方向按参考答案长度分为四个各 32 条的区间。EMA 相对动态组的 EN→SW 逐例平均差在四个区间均为负（约 -0.51、-0.92、-1.43、-0.69），128-token 截断触顶数两组也接近；因此当前差距不能简单归结为少数最长答案或生成截断。冻结组的 EN→SW 差距在后三个区间也为负。每个区间仅 32 条，此为事后描述，不据此修改平滑参数或重排预算。

`MASK_LAYER_FOOTPRINT_AUDIT.json` 将最终 BF16 差异按 28 层×Attention/MLP 归并。EMA 的 56 组差异比例均为 10.12%–14.60%，冻结版为 15.28%–20.58%，动态基线为 24.87%–33.92%；覆盖收缩遍及各层组件，不是单独某一层的产物。它仍是权重足迹，不是层的因果收益证据，不能用于重新指定训练层。

正式学习率前缀的复核结果见 `../sw_fullschedule_prefix_probe_20261004/RESULTS_ZH.md`。它排除了“旧 EMA 负结果只是因为 2048 步日程提前衰减”的简单解释；但两轮开发样本不同，不能将差值大小直接比较或断言所有全长 EMA 变体无效。此时值得继续的正式任务是补齐强方案一 `element_protected` 的 seed43 顺序复测及其固定测评，轨道见 `../sw_element15_seed43_20261004/README_ZH.md`；其结果不能在训练完成前预报。

`ELEMENT_PROTECTION_SEED42_PAIRED.json` 仅对**已发表的 seed42 正式测试结果**做事后逐例描述：方案一 15% 英语保护版相对去保护版，EN→SW +1.61、SW→EN +4.49 chrF++，英语阅读 +2.78 个百分点、GSM8K strict +16.45 个百分点；SW 阅读 -1.89，区间跨零。它支持补齐完全相同的 seed43 保护／去保护对照，**不能**用于继续调敏感度权重或挑新方法。seed43 两组均已在独立目录手动启动，冻结训练代码、同数据顺序和预算，完成后使用互相隔离而科学设置相同的固定测评工程；在正式 DONE 前不作跨顺序机制结论。
