# 15% 分数 EMA 动态掩码：独立开发集短训结果

**结论：未通过预注册双语收益门槛，停止该规则的完整训练和正式测评。** 新组与已冻结的 `uniform15_protected` 动态对照使用相同 Base、seed43 前 2048 个 D2 batch2、1,405,225 输入 token、FP32 AdamW、英语校准和 196,529,312／1,310,195,712 元素每步名额。新组只在每次重选前对矩阵内排名分数做 β=0.9 的跨刷新 EMA，不重跑或修改旧对照。新样本与上一轮冻结掩码开发集分别零重叠：双向翻译各 128 条、英语阅读与数学各 40 条；`eval/DATA_AUDIT.json` 记录身份。

前十次掩码重选的换入率中位数为 **6.11%**，全部 102 次重选中位数 **8.68%**；旧动态方法此前观测的前十次每次约 64%–68%。机制门槛（≤45%）达到，但双向翻译没有达到“至少一个方向逐例平均提升 ≥1 且区间下界 >0”的事前门槛，`eval/DECISION.json` 为 `stopped_by_preregistered_gate`。英语两项都是小样本诊断，阅读多对 2 题、数学多对 3 题，尤其数学区间跨零；不能宣称英语能力已经稳定改善，也不能与正式 IFEval/GSM8K 等同。逐样本答案与配对统计保存在 `eval/PER_SAMPLE.jsonl`、`eval/ENGLISH_PER_SAMPLE.jsonl`。

`WEIGHT_CHANGE_AUDIT.json` 逐张量核验：非候选权重相对 Base 完全不变；EMA 组 2048 步后 167,205,575（12.76%）个候选 BF16 值不同于 Base，旧动态组 385,793,215（29.45%）。这是最终值差异，不是历史被选元素并集，也不是 FLOP 节约。EMA 训练耗时 **0.838 GPU 小时**、峰值约 **19.97 GiB**；比旧动态组的约 0.729 GPU 小时慢，部分开销来自将 FP32 平滑分数存于 CPU 并于每次重选时传回 GPU，故不能声称本试验提高了计算效率。

真实模型短跑、2048 步 `TRAINING_DONE.json`、权重 SHA256、四项开发队列、`SERIES_COMPLETE.json` 的输出哈希均已核验；旧正式数据、旧代码和旧 checkpoint 未修改。四个队列及一次性衔接器均已正常退出，无自启或失败自动重试。此次仅一条训练顺序和 40 条／项英语样本，不能把它外推成全长训练的稳定收益。若以后重新研究“换入率—双语表现”曲线，应另建独立开发集和事前冻结的不同机制；本轮不会围绕同一小样本调 β。
