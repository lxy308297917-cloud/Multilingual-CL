# 全长模型逐组换权重：独立确认未通过

全长 seed43 LP 保护模型与同顺序、同预算的均匀保护模型在正式 EN→SW 翻译分别为 16.56、33.04 chrF++。在第三批 64 条 D2 开发样本上，逐个把均匀模型的一个“层×Attention/MLP”组换进 LP 模型，共 56 组。LP 基线 27.75 chrF++；39 个 LP 零预算组中 10 组得到正差，最大是 `27:mlp` 的 +1.06；17 个 LP 活跃组没有正差。每次换入只在内存中进行，并验证恢复原 LP 权重后基线预测逐字一致。原始输出和身份见 `swaps_attention.json`、`swaps_mlp.json`、`RESULTS.json`。

在完整筛查排名出来前，另一批 128 条开发样本及其 ID 已冻结。按固定规则选择零预算与活跃组各 3 个最高排名，另在每类剩余组中按固定哈希取 3 个对照，共 12 组。确认结果见 `confirm/CONFIRM_AUDIT.json`：

- `27:mlp` 从筛查 +1.06 降至确认 **+0.13 chrF++**；逐句差的描述性配对 95% 区间约 [-0.91, +1.52]。
- `26:attention` 从 +0.71 降至 **+0.26**；`21:attention` 从 +0.55 变为 **-0.07**。
- 固定哈希对照的零预算组也有约 +0.19 至 +0.43 的确认波动，没有出现筛查前几名明显优于对照的稳定模式。

因此**不根据此换组排名指定下一轮训练层或预算**。这是针对 56 组事后挑选的负结果；组间交互、换权重带来的整体预算改变，以及开发样本规模都限制因果解释。它并不否定“分散更新可能重要”，但目前没有足够证据说某一个层×模块是导致翻译退化的关键位置。两张筛查 GPU 和一张确认 GPU 均已释放；没有改动任何原模型文件，也没有启动相应的正式训练。
