# 冻结 Base 的 SW／英语逐模块梯度方向结果

只读探测与真实模型短跑均已完成，`DONE.json`、`DONE.smoke.json` 和 `STABILITY.json` 存在，`FAILED` 不存在；单卡已释放。模型权重没有写回。输入样本与代码哈希见 `PROBE_RELEASE.json`，56 组逐项余弦见 `ALIGNMENT.json`，28 层区组 bootstrap 见 `STABILITY.json`。完整探测约 150 秒，峰值显存 10.44 GiB。

各配对的分半排序均显示正相关，表明**在 Base 和这批训练侧样本上，哪些模块方向更同向的相对次序有一定可复测性**。但绝大多数 SW／英语余弦为正且接近零；EN→SW 只有 3/56 组在两半均为负，SW→EN 没有全样本为负的组。因此不能从 Base 的这批结果声称英语遗忘主要来自大量模块级梯度反向，也不宜直接推出“只投影冲突模块”的正式训练方案。

下一步若继续这条机制，应先在已有完成训练且英语下游确有变化的模型上，**用同批冻结开发输入只读复测**方向变化；这可以判断冲突是否在训练后出现。即使发现冲突，也仍需独立同预算、同训练顺序的短训验证更新规则，不能把余弦或 PPL 当作下游收益。
