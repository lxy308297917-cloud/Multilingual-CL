# EN–SW 表示对齐首轮实验：完成报告

截至2026-10-22上午，四组普通Dense SFT短训及Base/四个终点的独立开发评测全部完成；旧稀疏A/D/R轨道也已完成。**两种显式表示对齐均未通过冻结筛选，不升级长训，不启动层位/权重扫描、打乱配对、第二语言或稀疏组合。** 这是当前固定配置与小预算下的结果，不能推断所有表示对齐方法无效。

## 重要评测限制：零分不等于能力归零

冻结EN阅读主指标只接受单个字母，连正确“A. 选项内容”也判错；原explicit fallback也遗漏这类常见形式。数学主解析只接受boxed、指定冒号前缀或纯数值，漏掉了大量正确的普通文字答案。因此原始主分、原始输出和门结果均保留，但**不能把这些零分当作阅读/数学能力归零**。

在全部九个完整缓存端点上，统一补做两种**事后诊断**：阅读采用保守的明确选项标签/唯一选项文本解析；数学采用已存在本地GSM8K harness的flexible-extract及清理规则。它们不参与原筛选，不算独立确认，没有新增GPU前向。最后数字提取会误取中间量、科学计数法或较早的正确boxed答案，因此数学事后分也不等于经过人工核验的正确率。

| 方法 | EN阅读原strict / 事后选项解析 | EN数学原解析 / 事后flexible |
|---|---:|---:|
| Base | 5.47 / 78.91 | 78.91 / 74.22 |
| A | 0.00 / 60.94 | 0.00 / 36.72 |
| B | 0.00 / 73.05 | 0.00 / 36.72 |
| C | 0.00 / 67.97 | 0.00 / 35.16 |
| D | 0.00 / 70.70 | 0.00 / 34.38 |

格式改变和真实推理错误同时存在，不能把所有下降归因于其中一种。事后阅读诊断下B为73.05%、C为67.97%、D为70.70%；事后数学只作敏感性分析。SW阅读64 Token上限及其他任务截断也影响得分，未据此追加生成或改门。

## 旧稀疏A/D/R：另一个已完成的匹配问题

旧轨道每组2048步、734542主输入/287963主监督Token，196个Attention/MLP矩阵每矩阵约15%元素名额；BF16权重、FP32 Adam动量，其他张量冻结。与本轮Dense的预算、参数范围和状态精度不同，不能混表排名。

英语实际更新约束D相对无保护A，冻结数学得分提高22.66点，95%CI[13.28,31.25]；相对同池回放R只差−0.78点，CI[−10.94,9.38]，没有证据超过回放。EN→SW相对A低2.21 chrF++，CI[−3.78,−0.67]；相对R低1.75，CI[−3.14,−0.37]。阅读/数学同样存在上述格式敏感性，事后解析另列。D未通过冻结门，停止扩展。

D在746/2048步有非零QP乘子，283步因BF16实际残差不合格而整步拒绝写回，moment仍只推进一次；验收的实际写回约束违反数为0。局部约束不能保证累计不遗忘。mask并集最终约覆盖候选元素90.5%，所以“单步15%”不等于“全程只改15%”。

D1024固定配对门仅EN已知17、SW已知0，E/F及打乱配对S在实际窗口的权重/约束完全相同。已按预案停止E/F/S，没有降低判定阈值或改用R的后期掌握状态救活配对门。因此本轮没有配对机制有效或无效的实证结论，也不声称方法创新。

## 验收、成本与止损

- 七个训练终点均通过模型/optimizer/scheduler/步数/Token/哈希与有限性验收；稀疏mask与冻结参数、BF16实际残差亦通过。真实确定性恢复检查、最长约2k压力测试及必要数值检查已完成。
- 九个开发端点各1024条输出的来源ID/分组/顺序、提示与生成Token、结束/截断、解码和逐题/汇总评分经CPU重算核验；模型身份与训练收据一致。TensorBoard、逐步日志、可恢复checkpoint和RNG保留。
- 新对齐线四组训练合计5.71 GPU小时，包含准备、技术失败、表示诊断和开发的最终预算账为9.91 GPU小时，低于24；旧稀疏线含失败的队列账为19.82 GPU小时，低于32。两种账分别按本轨道定义，不将串行子步骤重复相加。
- Dense正式训练物理显存观测峰值A/B17315 MiB、C/D17335 MiB；2k压力测试17643 MiB。稀疏最高20959 MiB。分步观测和5秒只读采样均为观测峰值，并非连续硬件最大值；A完成前的历史峰值不由后启采样器重建。
- v1非确定性恢复问题和v2成本JSON序列化问题均保留失败证据、修复后独立重启并计费；没有通过改学习率、层、权重或挑中间checkpoint救分。v3辅助合批保持样本/负例库/平均损失，BF16累加顺序变化已披露。
- 新四组统一weight decay分组与旧HF Trainer的Norm/bias分组名义不同。已记录BF16衰减舍入审计及其推断范围，不称为旧配置的原样复现。
- 临时五卡权限仅用于本轮命名队列，现均恢复账号上限4；全局默认与历史运行配置未改，无开机自启/故障自动重启，其他用户/其他研究进程未被停止。

**决定：保留本轮负结果和全部有效产物，停止当前对齐原型与稀疏保护原型的扩展，不执行正式测试。** 下一轮首先应在未使用的训练侧开发材料上验收并冻结格式鲁棒解析和合理生成预算，再提出新的可检验机制；不在本开发集上反复换层、调权重或追加checkpoint。
